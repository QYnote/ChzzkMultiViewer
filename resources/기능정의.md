## 팝업

### 시청 목록 탭
- 현재 시청 중인 스트리머 목록 표시
- `▶ 메인` 버튼으로 대시보드 시작 시 메인 화면에 표시할 스트리머 지정
  - 목록의 맨 위(첫 번째) 스트리머가 대시보드의 메인 화면으로 사용되며, `▶ 메인` 버튼은 해당 스트리머를 목록 맨 위로 끌어올리는 방식으로 동작합니다.
- 목록 내 순서를 위/아래로 변경
  - 맨 위 스트리머(메인)에는 순서 변경/메인 지정 버튼이 표시되지 않으며, 두 번째 항목은 `▶ 메인`으로만 메인이 될 수 있고 `▲`로는 첫 번째 자리와 바로 바뀌지 않습니다.
- 개별 스트리머 삭제
- 대시보드 레이아웃 선택 (기본형 / 반전형 / 서브하단 / 서브상단)
- `멀티뷰 대시보드 열기`
  - 대시보드가 열려 있지 않으면 새 탭으로 열기
  - 이미 열려 있으면 새 탭을 만들지 않고 기존 탭으로 이동하며, 변경된 시청 목록을 자동으로 반영
    - 대시보드가 열려 있는 상태에서 시청 목록이나 레이아웃을 변경한 뒤 다시 누르면, 새 탭을 만들지 않고 기존 탭에 변경 내역만 전달되어 반영됩니다.

### 즐겨찾기 탭
- 자주 보는 스트리머를 영구 저장
- 시청 목록으로 복사 (이미 시청 목록에 있는 채널은 "추가됨"으로 표시되어 중복 추가 방지)
  - 시청 목록으로 복사해도 즐겨찾기 원본은 그대로 남습니다.
- 개별 삭제
  - 즐겨찾기에서 삭제해도 시청 목록에는 영향이 없습니다(서로 독립된 저장 공간).

### 스트리머 추가 탭
- **팔로잉 목록 연동**
  - 치지직 로그인 여부에 따라 안내 문구 또는 `내 팔로잉 목록 가져오기` 버튼 표시
    - 로그인 여부는 네이버 로그인 인증 쿠키 보유 여부로 판단하므로, 네이버 계정 로그인만 되어 있어도 "로그인됨"으로 인식될 수 있습니다.
    - 팔로잉 목록을 불러오지 못하면(세션 만료 등) 실패 안내와 함께 치지직 홈으로 이동하는 링크를 보여줍니다.
  - 비로그인 상태에서는 치지직 로그인 페이지로 이동하도록 안내
  - 불러온 목록은 LIVE 방송 우선 정렬, 현재 방송 중인 인원 수 표시
  - 각 항목에서 즐겨찾기 추가 / 시청 목록 추가 가능 (이미 추가된 항목은 비활성화 표시)
- **직접 추가**
  - 채널 고유 ID(32자리)와 표시할 이름 입력
    - 채널 ID는 정확히 32자리여야 등록됩니다.
  - 입력 시 특수문자 사용 제한 및 형식 검증
  - 이미 등록된 채널은 중복 추가 방지
    - 중복 검사는 시청 목록 기준으로만 수행됩니다(즐겨찾기와의 중복은 별도 검사하지 않음).

### 기타 설정 탭
- 자동 동기화 기능 켜기/끄기
  - 설정 변경은 즉시 저장되며, 대시보드가 열려 있어도 새로고침 없이 바로 적용됩니다.
- 자동 새로고침 기준이 되는 허용 지연 시간(초) 설정
- 현재 버전 정보 표시
  - 표시되는 버전은 manifest.json에 기록된 값입니다.

### 공통
- 추가/삭제/저장 등 작업 결과를 화면 하단 알림 메시지로 표시
  - 알림 메시지는 약 2.5초 후 자동으로 사라지며, 새 알림이 뜨면 이전 알림은 즉시 교체됩니다.

## 대시보드 공통

- 메인 화면 1채널 + 서브 화면 N채널을 동시에 시청
- 팝업에서 시청 목록이나 레이아웃을 변경하면 대시보드를 새로고침할 때 자동으로 반영
- **메인 ↔ 서브 스왑**: 서브 화면을 클릭하면 영상을 다시 불러오지 않고 메인 화면과 자리를 교체
  - 화면(영상)을 다시 불러오지 않고 표시 위치만 맞바꾸므로, 스왑 후에도 영상이 끊기지 않고 이어집니다.
- **방송 딜레이 표시**: 메인 화면 하단 바에 실시간 딜레이(초) 표시, 서브 화면에 마우스를 올리면 개별 딜레이 표시
  - 딜레이 값은 영상의 현재 재생 위치와 실시간 송출 위치의 차이를 1초 간격으로 계산한 값입니다.
- 전체 새로고침 / 메인 화면만 새로고침 버튼 제공
- **비방송 안내**: 시청 중인 채널이 생방송 중이 아니면 화면에 "방송중이 아닙니다"를 표시하고 자동 새로고침을 멈춤 (1분마다 재확인하여 방송이 다시 시작되면 자동으로 화면 복귀)
  - 비방송 상태인 화면은 자동 새로고침(자동 동기화) 대상에서도 함께 제외됩니다.
- **초기화 안내**: 화면을 새로 불러올 때(처음 열기, 새로고침, 메인↔서브 교체) "초기화 진행중입니다" 안내가 표시됩니다.
  - 와이드(넓은) 화면 전환이 완료되면 안내가 사라집니다.
  - 방송 중이 아닌 채널은 "방송중이 아닙니다" 표시와 함께 안내가 즉시 사라집니다.
  - 1분 안에 와이드 화면 전환이 되지 않으면 "수동 최대화 필요" 안내로 바뀝니다. 영상 위에서 직접 와이드 단축키(T)를 눌러 전환한 뒤 안내를 클릭하거나, 안내의 새로고침 버튼을 눌러 다시 시도할 수 있습니다.
  - 위 과정과 관계없이 일정 시간이 지나면 안내가 자동으로 사라집니다.
  - "초기화 진행중입니다"가 표시되는 동안에는 메인↔서브 화면 교환이 동작하지 않습니다 (안내가 사라진 뒤 다시 클릭).
- **와이드 모드 자동 전환**: 영상 재생이 시작되면 자동으로 단축키 입력을 보내 와이드(넓은) 화면으로 전환합니다.
  - 화면 전환이 바로 확인되지 않으면 최대 1분간 반복 시도합니다.
  - 메인 화면과 서브 화면 모두 동일하게 적용됩니다.
  - 메인↔서브 교체 시에도 두 화면 모두 다시 시도합니다.
- **자동 동기화**: 메인 화면과 각 서브 화면에 개별적으로 적용됩니다.
  - 딜레이가 설정한 기준 시간을 초과하면 해당 화면만 자동으로 새로고침
    - 새로고침 후 15초 동안은 같은 화면이 다시 새로고침되지 않습니다(과도한 재시도 방지).
  - 영상 신호가 없으면 약 10초 후 해당 화면만 자동 재시도
  - 켜기/끄기 및 허용 지연 시간 설정은 기타 설정 탭의 자동 동기화 설정 하나로 메인/서브 화면 전체에 공통 적용됩니다.

## 대시보드 메인 채널

- 현재 메인 스트리머의 채팅창을 자동으로 표시 (보이기/숨기기 상태 저장 및 복원)
  - 보이기/숨기기 상태는 메인 채널이 바뀌어도 그대로 유지됩니다.
- 영상 영역의 채팅 패널은 자동으로 접힌 상태로 표시

---

## 대시보드 서브 채널

- 서브 화면은 기본적으로 음소거 상태로 표시
- 서브 화면마다 음소거 토글과 볼륨 슬라이더로 개별 음량 조절
- 메인과 교체되면 기존 메인의 볼륨 수준을 그대로 이어받음
  - 스왑 시 볼륨 적용은 직후뿐 아니라 0.5초·1.5초 후에도 한 번씩 더 시도되어, 영상 로딩 타이밍 차이로 볼륨이 누락되는 것을 방지합니다.
- 마우스를 올리면 `✕` 버튼으로 해당 채널만 삭제, 새로고침 버튼 제공
  - 새로고침 버튼을 누르면 음소거 상태와 볼륨 50%로 초기화됩니다.
- 서브 채널 영역 전체를 버튼으로 접기/펼치기
- 서브하단/서브상단 레이아웃에서는 핸들을 드래그해 서브 채널 영역의 높이 조절 (자동 저장/복원)
  - 높이/접힘 상태는 레이아웃별로 저장되어 다음에 대시보드를 열 때도 유지됩니다.
