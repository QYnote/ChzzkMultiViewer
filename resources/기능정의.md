## 팝업

### 시청 목록 탭
- 현재 시청 중인 스트리머 목록 표시
- `▶ 메인` 버튼으로 대시보드 시작 시 메인 화면에 표시할 스트리머 지정
- 목록 내 순서를 위/아래로 변경
- 개별 스트리머 삭제
- 대시보드 레이아웃 선택 (기본형 / 반전형 / 서브하단 / 서브상단)
- `멀티뷰 대시보드 열기`
  - 대시보드가 열려 있지 않으면 새 탭으로 열기
  - 이미 열려 있으면 새 탭을 만들지 않고 기존 탭으로 이동하며, 변경된 시청 목록을 자동으로 반영

### 즐겨찾기 탭
- 자주 보는 스트리머를 영구 저장
- 시청 목록으로 복사 (이미 시청 목록에 있는 채널은 "추가됨"으로 표시되어 중복 추가 방지)
- 개별 삭제

### 스트리머 추가 탭
- **팔로잉 목록 연동**
  - 치지직 로그인 여부에 따라 안내 문구 또는 `내 팔로잉 목록 가져오기` 버튼 표시
  - 비로그인 상태에서는 치지직 로그인 페이지로 이동하도록 안내
  - 불러온 목록은 LIVE 방송 우선 정렬, 현재 방송 중인 인원 수 표시
  - 각 항목에서 즐겨찾기 추가 / 시청 목록 추가 가능 (이미 추가된 항목은 비활성화 표시)
- **직접 추가**
  - 채널 고유 ID(32자리)와 표시할 이름 입력
  - 입력 시 특수문자 사용 제한 및 형식 검증
  - 이미 등록된 채널은 중복 추가 방지

### 기타 설정 탭
- 자동 동기화 기능 켜기/끄기
- 자동 새로고침 기준이 되는 허용 지연 시간(초) 설정
- 현재 버전 정보 표시

### 공통
- 추가/삭제/저장 등 작업 결과를 화면 하단 알림 메시지로 표시

## 대시보드 공통

- 메인 화면 1채널 + 서브 화면 N채널을 동시에 시청
- 팝업에서 시청 목록이나 레이아웃을 변경하면 대시보드를 새로고침할 때 자동으로 반영
- **메인 ↔ 서브 스왑**: 서브 화면을 클릭하면 영상을 다시 불러오지 않고 메인 화면과 자리를 교체
- **방송 딜레이 표시**: 메인 화면 하단 바에 실시간 딜레이(초) 표시, 서브 화면에 마우스를 올리면 개별 딜레이 표시
- 전체 새로고침 / 메인 화면만 새로고침 버튼 제공
- **비방송 안내**: 시청 중인 채널이 생방송 중이 아니면 화면에 "방송중이 아닙니다"를 표시하고 자동 새로고침을 멈춤 (1분마다 재확인하여 방송이 다시 시작되면 자동으로 화면 복귀)

---

## 대시보드 메인 채널

- 현재 메인 스트리머의 채팅창을 자동으로 표시 (보이기/숨기기 상태 저장 및 복원)
- 영상 영역의 채팅 패널은 자동으로 접힌 상태로 표시
- **자동 동기화**
  - 딜레이가 설정한 기준 시간을 초과하면 자동으로 새로고침
  - 영상 신호가 없으면 일정 시간 후 자동 재시도
- 영상 재생 시 치지직 와이드 모드로 자동 전환

---

## 대시보드 서브 채널

- 서브 화면은 기본적으로 음소거 상태로 표시
- 서브 화면마다 음소거 토글과 볼륨 슬라이더로 개별 음량 조절
- 메인과 교체되면 기존 메인의 볼륨 수준을 그대로 이어받음
- 마우스를 올리면 `✕` 버튼으로 해당 채널만 삭제, 새로고침 버튼 제공
- 서브 채널 영역 전체를 버튼으로 접기/펼치기
- 서브하단/서브상단 레이아웃에서는 핸들을 드래그해 서브 채널 영역의 높이 조절 (자동 저장/복원)
