# Logical Viewpoint

> **다루는 내용:** 시스템이 어떤 모듈로 나뉘고, 각 모듈이 무엇을 책임지는가
> **갱신 트리거:** 모듈이 추가·제거되거나 책임 범위가 바뀔 때

이 관점은 **개발자의 관심사**를 다룹니다.
- "시스템은 어떤 모듈로 이루어져 있나?"
- "각 모듈의 책임은 무엇인가?"
- "모듈들은 무엇을 주고받나?"
