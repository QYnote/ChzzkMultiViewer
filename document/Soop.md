# SOOP

> **다루는 내용:** SOOP 플랫폼이 정한 값과 규칙 (주소 형식, 인증 쿠키, 화면 요소, 고화질 재생 대응)
> **갱신 트리거:** SOOP이 주소·쿠키·화면 구조를 바꿔 대응이 필요할 때

## 본문

여기 적힌 값은 **SOOP이 정한 것**이라 우리가 바꿀 수 없다. SOOP 쪽이 바뀌면 이 문서와 코드를 함께 고쳐야 한다.

### 1. SOOP이 정한 값

우리가 바꿀 수 없는 값들이다. SOOP이 바꾸면 여기를 고쳐야 한다.

#### 1.1 채널 ID

- 영문/숫자 조합, 자릿수 규칙 없음
- 방송 주소에서 확인한다

#### 1.2 주소 형식

| 용도 | 주소 |
|---|---|
| 방송 화면 | `https://play.sooplive.com/{채널ID}` |
| 팔로잉 목록 | `https://myapi.sooplive.com/api/favorite` |
| 생방송 상태 | `https://live.sooplive.com/afreeca/player_live_api.php` |
| 프로필 사진 | `https://stimg.sooplive.com/LOGO/{채널ID 앞 2자}/{채널ID}/m/{채널ID}.webp` |

- 방송 화면 주소에는 확장 프로그램이 만든 화면임을 알리는 표시를 붙인다.
- **채팅을 지원하지 않는다.**
- 생방송 상태는 다른 조회와 달리 주소가 아니라 본문에 값을 실어 보내는 방식으로 요청한다.

#### 1.3 로그인 판단과 인증 쿠키

로그인 여부를 **즐겨찾기 목록을 실제로 요청해** 정상 목록이 돌아오는지로 판단한다. 치지직처럼 쿠키 존재만 보지 않으므로 오탐이 없다.

쿠키는 이름을 지정하지 않고 **두 도메인의 것을 전부** 모은다.

| 도메인 | 우선순위 |
|---|---|
| `sooplive.com` | 이름이 겹치면 이쪽이 이긴다 |
| `sooplive.co.kr` | |

### 2. 대응이 필요했던 문제

SOOP 방송 화면을 우리 칸에 끼워 넣으면서 생긴 문제와 그 해결이다.

#### 2.1 고화질 재생 대응

SOOP 고화질 재생기는 **로컬 앱이 깔려 있는지 확인하려고 내 컴퓨터 주소(`127.0.0.1`·`localhost`)로 요청을 보낸다.** 그대로 두면 브라우저 권한 팝업이 뜬다.

그래서 이 요청을 전부 실패시킨다. 재생기가 로컬 앱이 없다고 판단해 일반 재생 방식으로 자동 전환하고, 권한 팝업도 뜨지 않는다.

**주의**
- ⚠️ 이 차단은 방송 페이지 자체의 코드를 가로채야 해서, 확장 프로그램 전용 영역이 아니라 **페이지와 같은 실행 영역**에 스크립트를 넣어야 한다. SOOP에만 이 처리가 있는 이유다.

#### 2.2 좁은 칸에서의 화면 깨짐

SOOP 방송 페이지는 **폭이 좁아지면 화면이 잘리고 왼쪽에 빈 여백이 생긴다.** 페이지가 정한 최소 너비 아래로는 제대로 그려지지 않는데, 저희가 페이지 안을 고칠 수는 없다.

그래서 칸이 좁을 때는 **페이지를 넉넉한 너비로 그린 뒤 칸 크기에 맞춰 줄여서 끼운다.** 높이는 칸의 가로세로 비율을 그대로 따라가므로 찌그러지거나 여백이 생기지 않는다.

**주의**
- ⚠️ 이 축소와 영역 확대는 **같은 변형을 함께 쓴다.** 확대 중에는 확대가 이기고, 확대를 풀면 축소로 돌아온다. 한쪽만 따로 적용하면 서로 덮어써서 화면이 어긋난다.
- ⚠️ 확대할 영역은 **눈에 보이는 화면 기준**으로 고르게 되므로, 줄어든 만큼을 되돌려 페이지 좌표로 바꿔서 기억해야 한다. 그래야 줄여 놓은 상태에서 골라도 원하는 부분이 확대된다.
- ⚠️ 기준 너비는 관측으로 정한 값이다. SOOP이 화면 구조를 바꾸면 다시 재야 한다.

### 화면 요소

방송 페이지 안에서 조작하는 부분이다. SOOP이 화면 구조를 바꾸면 동작하지 않으므로, 증상이 생기면 여기부터 확인한다.

| 대상 | 판별·조작 방법 |
|---|---|
| 넓은 화면 전환 버튼 | 화면 모드 전환 버튼을 누른다 |
| 넓은 화면 여부 | 화면 전체에 확대 상태를 뜻하는 표시가 붙었는지 본다 |
| 고화질 연결 안내 팝업 | 로컬 앱 미설치를 뜻하는 버튼이 나타나면 눌러 닫는다 |
| 채팅 영역 | 채팅 영역이 보이면 닫기 버튼을 눌러 접는다 |
| 광고 재생 중 여부 | 건너뛰기 버튼 요소가 있는지 본다 |
| 광고 건너뛰기 버튼 | 버튼이 활성화되고 보이는 상태면 누른다 |

**주의**
- ⚠️ 채팅 영역 닫기 버튼은 누를 때 페이지 보안 정책 위반 오류가 날 수 있어, 누르기 전에 연결 주소를 떼어낸 뒤 누른다.
