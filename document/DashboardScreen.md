# 대시보드 화면

> **다루는 내용:** 대시보드에서 사용자가 할 수 있는 조작과 화면에 나타나는 안내
> **갱신 트리거:** 대시보드의 조작 방법이나 화면 배치가 바뀔 때

## 본문

### 1. 칸 나누기

화면이 어떤 규칙으로 칸으로 갈라지는지, 처음 열었을 때 어떤 모양이 되는지를 다룬다.

#### 1.1 화면 배치

채널마다 칸을 하나씩 준다. 모든 칸이 동등하며 주·보조 구분이 없다. 배치는 **칸을 쪼개서** 만든다.

```
┌──────────┬──────────┐   자르기를 거듭해 원하는 모양을 만든다
│          │  채널 B  │
│  채널 A  ├──────────┤   왼쪽은 세로 전체를 쓰고
│          │  채널 C  │   오른쪽만 위아래로 나뉜 모양
└──────────┴──────────┘
```

자를 때 그은 선은 **언제나 그 칸을 끝에서 끝까지 가로지른다.** 그래서 아래처럼 어느 방향으로도 끝까지 자를 수 없는 모양은 만들 수 없다.

```
┌──────┬───┐
│  A   │   │   가로로도 세로로도 관통하는 선이 없어
├───┬──┤ B │   이 모양은 만들어지지 않는다
│ C │E │   │
│   ├──┴───┤
│   │  D   │
└───┴──────┘
```

칸 크기는 **비율로 기억한다.** 창 크기를 바꿔도 배치가 그대로 유지된다.

#### 1.2 처음 열었을 때의 배치

저장된 배치가 없으면 채널 수에 맞춰 자동으로 깐다.

| 채널 수 | 모양 |
|---|---|
| 1 | 화면 전체 |
| 2 | 좌우 반반 |
| 3 | 왼쪽에 위아래 둘, 오른쪽에 큰 칸 하나 |
| 4 | 2×2 |
| 5 이상 | 정사각형에 가까운 균등 격자 |

한 번 배치가 저장된 뒤로는 이 순서를 쓰지 않는다.

### 2. 직접 조작하기

사용자가 손으로 하는 일이다.

#### 2.1 화면 조작하기

| 하고 싶은 것 | 어떻게 |
|---|---|
| 칸 크기 조절 | 칸 사이 경계를 드래그 |
| 자리 바꾸기 | 칸의 손잡이를 잡아 다른 칸 **가운데**로 끌어다 놓기 |
| 칸 쪼개서 넣기 | 손잡이를 잡아 다른 칸 **가장자리**로 끌어다 놓기 |
| 끌기 취소 | 놓기 전에 ESC |
| 화면 하나만 새로고침 | 칸의 새로고침 버튼 |
| 채널 하나만 빼기 | 칸의 닫기 버튼 |
| 화면 일부만 크게 보기 | 칸 메뉴에서 확대를 고른 뒤 원하는 영역을 드래그 |
| 소리 조절 | 방송 화면 안의 조절 기능을 그대로 사용 |

- 끌어다 놓을 때 **어디에 들어갈지 미리 보여준다.** 가운데는 칸 전체가, 가장자리는 그쪽 절반이 물든다.
- 칸을 빼면 **형제 칸이 그 자리를 흡수한다.** 빈 자리가 남지 않는다.
- 조절한 배치는 **바로 저장된다.** 다시 열어도 그대로다.
- 칸이 좁아지면 **화면 전체가 비율 그대로 줄어든다.** 방송 페이지가 좁은 폭에서 깨지거나 삐져나가는 것을 피하기 위한 처리이며, 줄어들기 시작하는 폭은 플랫폼마다 다르다 — [치지직](Chzzk.md#14-좁은-칸에서-생기는-스크롤-막대) · [SOOP](Soop.md#22-좁은-칸에서의-화면-깨짐). 확대 중에는 확대가 우선한다.
- 팝업에서 시청 목록이 바뀌면, 빠진 채널의 칸은 사라지고 새 채널은 가장 넓은 칸을 쪼개서 들어간다.

**주의**
- ⚠️ 방송 화면 위에서 누른 마우스는 방송 페이지가 먼저 가져간다. 그래서 칸 아무 곳이나 잡아 끌 수는 없고 **손잡이를 잡아야** 한다.
- ⚠️ 칸은 정해진 최소 크기보다 작아지지 않는다. 쪼갠 결과가 그보다 작아질 상황이면 **가장자리를 내주지 않고** 자리 바꾸기만 받는다.

#### 2.2 칸 조작 줄

각 칸의 오른쪽 위에 조작이 모여 있다. 마우스를 올리면 나타난다.

```
┌────────────────────────────────────────┐
│  채널 표시        딜레이 · 새로고침 ·    │
│                   손잡이 · 메뉴 · 닫기   │
│                                        │
│              방송 화면                  │
│                                        │
│   ← 아래쪽은 방송 페이지의 조작 바 자리 → │
└────────────────────────────────────────┘
```

화면 아래쪽에는 아무것도 놓지 않는다. 방송 페이지가 자기 조작 바를 그곳에 그리기 때문이다. 덕분에 **소리·전체화면 같은 방송 페이지 기능을 그대로 쓸 수 있다.**

#### 2.3 소리 다루기

- 소리는 **방송 화면 안의 조절 기능**으로 다룬다. 이 프로그램은 음량을 건드리지 않는다.
- 음량은 **방송 페이지가 채널마다 기억한다.** 다시 열면 그 채널에서 마지막에 쓰던 크기로 시작한다.
- 처음 보는 채널은 방송 페이지의 기본값으로 시작한다.

**주의**
- ⚠️ 여러 칸의 소리가 동시에 날 수 있다. 원하지 않는 칸은 그 방송 화면에서 직접 음소거한다.

### 3. 화면이 알려주고 스스로 하는 것

사용자가 시키지 않아도 화면이 알아서 하거나 알려주는 것들이다.

#### 3.1 화면에 나타나는 안내

| 안내 | 언제 | 언제 사라지나 |
|---|---|---|
| **초기화 진행중입니다** | 화면을 새로 불러올 때 — 최초 진입, 새로고침 | 넓은 화면 전환이 끝나면. 늦어도 65초 뒤 |
| **수동 최대화 필요** | 1분 안에 넓은 화면 전환이 안 됐을 때 | 영상 위에서 넓은 화면 단축키(T)를 누른 뒤 안내를 클릭하거나, 안내의 새로고침 버튼을 누를 때 |
| **방송중이 아닙니다** | 시청 중인 채널이 생방송 중이 아닐 때 | 1분마다 다시 확인해 방송이 시작되면 |

**주의**
- ⚠️ "수동 최대화 필요"는 저절로 사라지지 않는다. 직접 닫아야 한다.
- ⚠️ 방송이 없는 칸에서는 조작 줄에 **닫기만** 남는다.

#### 3.2 자동으로 처리되는 것

- **넓은 화면 자동 전환** — 영상이 시작되면 자동으로 넓은 화면으로 바꾼다. 확인되지 않으면 최대 1분간 다시 시도한다.
- **광고 자동 건너뛰기** — 건너뛰기 버튼이 나타나는 즉시 누른다. 광고 하나당 한 번만 시도한다.
- **자동 동기화** — 방송 딜레이가 설정한 기준을 넘으면 그 칸만 새로고침한다. 영상 신호가 끊겨도 잠시 뒤 새로고침한다. 칸마다 따로 적용된다.
  - **광고 중이거나 방송 중이 아닌 칸은 대상에서 빠진다.**
  - 확인 주기와 재시도 간격은 [Dashboard](Dashboard.md) 참고.
- **SOOP 전용 처리** — 고화질 연결 안내 팝업을 자동으로 닫고, 브라우저 권한 팝업이 뜨지 않도록 로컬 앱 감지 요청을 막는다.

#### 3.3 칸의 채널 표시

- 칸 왼쪽 위에 프로필 사진이나 채널 이름이 표시된다. 표시 방식은 팝업의 기타설정에서 네 가지 중 고른다.
- 프로필 사진 크기는 칸 높이의 1/4, 원본 크기, 정해진 상한 중 가장 작은 값으로 자동 조절되고, 칸 크기가 바뀌면 함께 변한다.
- 방송 딜레이는 마우스를 올릴 때 조작 줄에 표시된다.
- 방송 중이 아닌 칸은 마우스를 올리지 않아도 닫기 버튼이 항상 보인다.
