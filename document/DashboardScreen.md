# 대시보드 화면

> **다루는 내용:** 대시보드에서 사용자가 할 수 있는 조작과 화면에 나타나는 안내
> **갱신 트리거:** 대시보드의 조작 방법이나 화면 배치가 바뀔 때

## 본문

### 화면 배치

화면은 **메인 플레이어 · 서브 채널 · 채팅** 세 영역으로 이루어진다. 배치는 팝업의 기타설정 탭에서 네 가지 중 하나로 고른다.

**기본형** — 서브가 왼쪽, 채팅이 오른쪽

```
┌──────────┬──────────────────────────┬──────────┐
│  서브    │      메인 플레이어        │   채팅   │
│ [타일]   │                          │          │
│ [타일]   │  🔴 스트리머명 [↻ 새로고침] │          │
└──────────┴──────────────────────────┴──────────┘
```

**반전형** — 서브와 채팅이 서로 자리를 맞바꾼다

```
┌──────────┬──────────────────────────┬──────────┐
│  채팅    │      메인 플레이어        │   서브   │
│          │                          │  [타일]  │
│          │  🔴 스트리머명 [↻ 새로고침] │  [타일]  │
└──────────┴──────────────────────────┴──────────┘
```

**서브하단** — 서브가 화면 전체 폭을 쓰는 가로 띠가 된다

```
┌─────────────────────────────────────┬──────────┐
│           메인 플레이어              │   채팅   │
│      🔴 스트리머명 [↻ 새로고침]       │          │
├─────────────────────────────────────┴──────────┤
│  [타일] [타일] [타일]  →  가로 스크롤            │
└────────────────────────────────────────────────┘
```

**서브상단** — 가로 띠가 위로 간다

```
┌────────────────────────────────────────────────┐
│  [타일] [타일] [타일]  →  가로 스크롤            │
├─────────────────────────────────────┬──────────┤
│           메인 플레이어              │   채팅   │
│      🔴 스트리머명 [↻ 새로고침]       │          │
└─────────────────────────────────────┴──────────┘
```

| 배치 | 서브 위치 | 채팅 위치 | 크기 조절 |
|---|---|---|---|
| 기본형 | 왼쪽 세로 | 오른쪽 | 너비 (저장 안 됨) |
| 반전형 | 오른쪽 세로 | **왼쪽** | 너비 (저장 안 됨) |
| 서브하단 | 아래 가로 띠 | 메인 오른쪽 | 높이 (저장됨) |
| 서브상단 | 위 가로 띠 | 메인 오른쪽 | 높이 (저장됨) |

- 반전형은 서브뿐 아니라 **채팅도 함께** 자리를 옮긴다.
- 서브하단/서브상단에서는 서브 띠가 메인과 채팅을 가로질러 **화면 전체 폭**을 쓴다.

### 화면 조작하기

| 하고 싶은 것 | 어떻게 |
|---|---|
| 메인 바꾸기 | 서브 화면을 클릭. 영상을 다시 불러오지 않고 자리만 맞바뀐다 |
| 서브 순서 바꾸기 | 서브 타일을 드래그 |
| 서브 하나만 빼기 | 타일에 마우스를 올려 `✕` |
| 화면 하나만 새로고침 | 메인은 하단 바의 새로고침 버튼, 서브는 타일의 새로고침 버튼 |
| 서브 영역 접기 / 펼치기 | 서브 영역의 접기 버튼 |
| 서브 영역 크기 조절 | 경계의 핸들을 드래그 |
| 서브 목록 좌우로 넘기기 | 서브하단·서브상단에서 목록 위에 마우스를 올리고 휠 |
| 서브 화면 일부만 크게 보기 | 확대 버튼을 누른 뒤 원하는 영역을 드래그. 버튼으로 원래대로 |

- 메인을 바꾸면 그 결과가 **시청 목록에도 저장된다.** 팝업의 메인도 함께 바뀌고 새로고침해도 유지된다.
- 팝업에서 시청 목록이나 배치를 바꾸면 대시보드를 새로고침할 때 반영된다.
- 서브 영역 **높이는 저장**되지만 **너비는 저장되지 않는다.** 다시 열면 초기 너비로 돌아간다.
  - 높이는 서브하단과 서브상단이, 접힘 상태는 네 배치가 **하나의 값을 함께 쓴다.** 한쪽에서 바꾸면 다른 쪽에도 적용된다.

**주의**
- ⚠️ 서브 영역 너비는 화면 전체의 **40%까지만** 넓힐 수 있다. 그 이상에서 생기는 스크롤을 없애는 방법을 아직 찾지 못해 걸어둔 제한이다.

### 소리 다루기

- 서브 화면은 **기본적으로 음소거**다. 타일에 마우스를 올리면 음소거 토글과 볼륨 슬라이더가 나온다.
- 볼륨 크기는 **채널마다 따로 기억된다.** 메인으로 올라오면 그 채널에서 마지막에 쓰던 볼륨으로 재생된다.
- 음소거 여부는 교체할 때 **기존 메인에서 이어받는다.** 기존 메인이 음소거였다면 새 메인도 음소거로 시작하되, 플레이어에서 직접 풀 수 있다.
- 서브를 새로고침하면 음소거 상태로 돌아간다.
- 교체하면 두 화면을 다시 불러오므로, 새 메인은 잠깐 음소거로 시작했다가 준비가 끝나면 자동으로 맞춰진다.

### 화면에 나타나는 안내

| 안내 | 언제 | 언제 사라지나 |
|---|---|---|
| **초기화 진행중입니다** | 화면을 새로 불러올 때 — 최초 진입, 새로고침, 메인↔서브 교체 | 넓은 화면 전환이 끝나면. 늦어도 65초 뒤 |
| **수동 최대화 필요** | 1분 안에 넓은 화면 전환이 안 됐을 때 | 영상 위에서 넓은 화면 단축키(T)를 누른 뒤 안내를 클릭하거나, 안내의 새로고침 버튼을 누를 때 |
| **방송중이 아닙니다** | 시청 중인 채널이 생방송 중이 아닐 때 | 1분마다 다시 확인해 방송이 시작되면 |

**주의**
- ⚠️ "초기화 진행중"이 떠 있는 동안에는 **메인↔서브 교체가 되지 않는다.** 안내가 사라진 뒤 다시 클릭한다.
- ⚠️ "수동 최대화 필요"는 저절로 사라지지 않는다. 직접 닫아야 한다.

### 자동으로 처리되는 것

- **넓은 화면 자동 전환** — 영상이 시작되면 자동으로 넓은 화면으로 바꾼다. 확인되지 않으면 최대 1분간 다시 시도하고, 메인·서브 모두, 교체할 때도 다시 시도한다.
- **광고 자동 건너뛰기** — 건너뛰기 버튼이 나타나는 즉시 누른다. 광고 하나당 한 번만 시도한다.
- **자동 동기화** — 방송 딜레이가 설정한 기준을 넘으면 그 화면만 새로고침한다. 영상 신호가 없으면 약 10초 뒤 다시 시도한다. 메인과 각 서브에 따로 적용된다.
  - 같은 화면은 새로고침 후 15초 동안 다시 새로고침되지 않는다.
  - **광고 중이거나 방송 중이 아닌 화면은 대상에서 빠진다.**
- **SOOP 전용 처리** — 고화질 연결 안내 팝업을 자동으로 닫고, 브라우저 권한 팝업이 뜨지 않도록 로컬 앱 감지 요청을 막는다.

### 메인 화면의 채팅

- 메인 스트리머의 채팅창이 자동으로 표시된다. 보이기/숨기기 상태는 저장되고, **메인이 바뀌어도 유지**된다.
- SOOP은 채팅을 지원하지 않아 자동으로 숨겨진다.
- 영상 위에 겹치는 채팅 패널은 자동으로 접힌 상태로 시작한다.

### 서브 화면의 채널 표시

- 서브 화면 왼쪽 위에 프로필 사진이나 채널 이름이 표시된다. 표시 방식은 팝업의 기타설정에서 네 가지 중 고른다.
- 프로필 사진 크기는 서브 화면 높이의 1/4과 원본 크기 중 작은 값으로 자동 조절되고, 화면 크기가 바뀌면 함께 변한다.
- 메인과 자리를 바꿔도 그 자리의 채널에 맞는 표시로 함께 바뀐다.
- 방송 딜레이는 메인은 하단 바에 항상, 서브는 마우스를 올릴 때 표시된다.
- 방송 중이 아닌 서브 채널은 마우스를 올리지 않아도 `✕` 버튼이 항상 보인다.
