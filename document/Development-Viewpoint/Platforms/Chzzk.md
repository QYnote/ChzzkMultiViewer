# 치지직 (Chzzk)

> **다루는 내용:** 치지직 플랫폼이 정한 값과 규칙 (주소 형식, 인증 쿠키, 화면 요소)
> **갱신 트리거:** 치지직이 주소·쿠키·화면 구조를 바꿔 대응이 필요할 때

## 본문

### 1. 치지직이 정한 값

**치지직이 정한 것**이라 우리가 바꿀 수 없다. 치지직 쪽이 바뀌면 이 문서와 코드를 함께 고쳐야 한다.

#### 1.1 채널 ID

- 정확히 32자리 영문/숫자
- 방송 주소에서 확인한다

#### 1.2 주소 형식

| 용도 | 주소 |
|---|---|
| 방송 화면 | `https://chzzk.naver.com/live/{채널ID}` |
| 팔로잉 목록 | `https://api.chzzk.naver.com/service/v1/channels/followings` |
| 생방송 상태·프로필 사진 | `https://api.chzzk.naver.com/service/v1/channels/{채널ID}` |

#### 1.3 로그인 판단과 인증 쿠키

로그인 여부를 **쿠키가 있는지로만** 판단한다. 실제 요청을 보내 확인하지 않는다. 판단은 팝업이 브라우저 쿠키를 직접 보고 한다.

| 쿠키 이름 | 뜻 | 로그인 판단 | 방송 화면·조회에 실어 보냄 |
|---|---|---|---|
| `NID_AUT` | 네이버 로그인 인증 | ✅ 둘 다 있어야 로그인으로 본다 | ✅ |
| `NID_SES` | 네이버 세션 | ✅ | ✅ |
| `nid_inf` | 네이버 부가 정보 | — | ✅ |

**주의**
- ⚠️ 세 쿠키는 치지직 전용이 아니라 **네이버 전체에서 쓰이는 로그인 쿠키**다. 그래서 치지직에 한 번도 들어간 적이 없어도 네이버에만 로그인돼 있으면 "치지직 로그인됨"으로 판단된다.
- ⚠️ 쿠키 이름이 바뀌거나 세션이 만료되면 팔로잉 목록을 불러오지 못한다. 이때는 실패 안내와 함께 치지직 홈으로 가는 링크를 보여준다.

#### 1.4 좁은 칸에서 생기는 스크롤 막대

치지직 방송 페이지는 **일정 폭 아래로 줄어들지 않는다.** 칸이 그보다 좁으면 페이지가 칸 밖으로 삐져나가 스크롤 막대가 생긴다. 페이지 안을 고칠 수는 없다.

그래서 칸이 좁을 때는 **페이지를 그 최소 폭으로 그린 뒤 칸 크기에 맞춰 줄여서 끼운다.** [SOOP](Soop.md#22-좁은-칸에서의-화면-깨짐)에 쓰던 방법과 같고, 값만 플랫폼마다 다르다.

**주의**
- ⚠️ **넓은 화면과는 무관한 제약이다.** 넓은 화면이 걸린 상태에서도 생긴다. 넓은 화면을 다시 걸거나 껐다 켜는 방법으로는 없어지지 않는다.
- ⚠️ 가로 막대가 생기면 그 두께만큼 세로가 모자라 **세로 막대까지 딸려 나온다.** 가로를 잡으면 둘 다 사라지므로 세로를 따로 다루지 않는다.
- ⚠️ 기준 너비는 관측으로 정한 값이다. 칸을 여러 크기로 줄여 봐도 페이지 폭이 더 내려가지 않는 지점을 최소 폭으로 삼았다. 치지직이 화면 구조를 바꾸면 다시 재야 한다.
- ⚠️ 잰 값보다 **조금 높여 두었다.** 흔히 쓰는 화면을 좌우로 나눈 칸이 잰 값 바로 위로 빠져, 그 칸만 줄이지 않고 그리는 바람에 옆 칸과 배치가 어긋나 보였기 때문이다.
- ⚠️ **기준보다 넓은 칸은 여전히 줄이지 않는다.** 그런 칸은 다른 칸과 배치가 어긋나 보이며, 화면이 클수록 자주 나온다. 경계를 없애려면 칸 크기와 무관하게 늘 같은 폭으로 그려야 하는데, 그러면 큰 칸이 확대되어 흐릿해진다. 지금은 흐릿해지지 않는 쪽을 택했다.

#### 1.5 다른 페이지 안에 끼워 넣기 제한

치지직 페이지는 응답에 **"이 페이지를 어느 주소 안에 끼워 넣을 수 있는가"를 정하는 보안 규칙**을 실어 보낸다. 허용된 곳은 치지직 자신과 네이버 주소뿐이다.

| 항목 | 값 |
|---|---|
| 규칙이 실리는 곳 | 응답 헤더 `Content-Security-Policy` |
| 규칙 내용 | `frame-ancestors 'self' https://naver.com https://*.naver.com` |
| 걸리는 범위 | 치지직 페이지 전체 — 방송 주소와 첫 화면 모두 |
| 확인한 날 | 2026-10-07 |

대시보드는 네이버 주소가 아니므로 이 규칙에 걸려, 칸에 "chzzk.naver.com이(가) 차단되었습니다"가 뜬다. 대응은 [Background](../../Logical-Viewpoint/Components/Background.md)가 맡는다.

**주의**
- ⚠️ 이 규칙이 생기기 전에는 아무 처리 없이 칸에 끼워 넣어졌다. 우리 쪽은 바뀐 것이 없었으므로 **치지직 쪽 변경**이다.
- ⚠️ 같은 목적의 옛 방식 헤더(`X-Frame-Options`)는 **실리지 않는다.** 외부 자료에는 그쪽으로 소개된 경우가 있으나 확인일의 실제 응답에는 없었다. 증상이 다시 생기면 추측하지 말고 실제 응답 헤더부터 본다.
- ⚠️ 확인일 기준으로 이 헤더에는 **끼워 넣기 제한 하나만** 실려 있다. 같은 헤더에 다른 보안 규칙이 함께 실리기 시작하거나, 제한이 다른 헤더로 옮겨 가면 대응을 다시 확인해야 한다. 허용 목록만 바뀌는 것은 영향이 없다.

### 화면 요소

방송 페이지 안에서 조작하는 부분이다. 조작이 먹지 않는 증상이 생기면 여기부터 확인한다.

| 대상 | 판별·조작 방법 |
|---|---|
| 넓은 화면 전환 버튼 | 이름표가 "넓은 화면"인 버튼을 누른다 |
| 넓은 화면 여부 | 재생기 영역에 확대 상태를 뜻하는 표시가 붙었는지 본다 |
| 채팅 접기 버튼 | 이름표가 "채팅 접기"인 버튼을 누른다 |
| 광고 재생 중 여부 | 건너뛰기 안내 요소가 있는지 본다 |
| 광고 건너뛰기 버튼 | 건너뛰기 버튼이 숨김 상태가 아니면 누른다 |
