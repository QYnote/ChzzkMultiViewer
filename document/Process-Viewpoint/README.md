# Process Viewpoint

> **다루는 내용:** 실행 중에 모듈들이 어떤 순서로 움직이는가
> **갱신 트리거:** 하위 문서가 추가·제거될 때

이 관점은 **개발자·시험하는 사람의 관심사**를 다룹니다.
- "사용자가 버튼을 누르면 실제로 무엇이 일어나나?"
- "각 실행 환경은 언제 생기고 사라지나?"
