# 배포와 설치 환경

> **다루는 내용:** 완성본이 어디로 나가고 어떻게 설치되는지, 설치 때 받는 권한과 그 사유
> **갱신 트리거:** 배포 경로나 설치 방식이 바뀌거나, 권한을 더하거나 뺄 때

## 본문

### 배포 경로

| 경로 | 무엇이 나가나 | 자세한 곳 |
|---|---|---|
| GitHub 저장소 | 소스 전체. 배포할 때마다 배포용 갈래가 갱신된다 | [Git](../Development-Viewpoint/Git.md) |
| 배포 ZIP | 실행에 필요한 파일만 묶은 압축 파일 | [Build](../Development-Viewpoint/Build.md) |

- 버전 번호를 올리는 기준은 [Git](../Development-Viewpoint/Git.md#버전-규칙)에 있다.
- 배포 절차의 실행 순서는 저장소 루트의 `CLAUDE.md`에 있다.

### 설치 방식

크롬의 **압축 해제된 확장 프로그램 불러오기**로 설치한다. 절차는 최상위 [README](../../README.md#설치-방법-로컬-개발자-모드) 참고.

- 이 방식은 고른 폴더를 **그 자리에서 그대로** 읽는다. 크롬이 다른 곳으로 복사해 두지 않으므로, 폴더를 옮기거나 지우면 확장이 동작하지 않는다.
- 자동 업데이트가 없다. 새 버전은 폴더 내용을 바꾼 뒤 확장 관리 화면에서 새로고침해야 반영된다.
- 확장의 고유 식별값이 **불러온 폴더 경로로 정해진다.** 같은 소스라도 다른 폴더에서 불러오면 다른 확장으로 취급되어, 저장해 둔 시청 목록·즐겨찾기 등이 이어지지 않는다.

### 설치 때 받는 권한

권한은 설치할 때 한 번에 받는다. 쓰는 도중에 따로 묻지 않는다.

| 권한 | 왜 필요한가 | 쓰는 곳 |
|---|---|---|
| 브라우저 저장소 | 시청 목록·즐겨찾기·저장된 목록·설정·배치를 보관한다 — [저장 데이터](DataSchema.md) | Popup · Dashboard |
| 탭 조회 | 이미 열린 대시보드 탭을 찾아 그리로 이동하고 변경을 알린다 | Popup |
| 네트워크 규칙 | 방송 화면과 조회 요청에 로그인 쿠키를 싣는다. 대시보드가 띄운 방송 화면에서 끼워 넣기 제한을 걷어 낸다 | Background |
| 쿠키 읽기 | 실어 보낼 로그인 쿠키를 읽는다. 치지직 로그인 여부를 판단한다 | Background · Popup |
| 스크립트 등록 | SOOP 전용 스크립트를 방송 페이지와 **같은 실행 영역**에 등록한다. 설정 파일로 선언하는 방식으로는 그 영역에서 도는 것이 보장되지 않는다 | Background |
| 사이트 접근 — 치지직·네이버·SOOP | 위 쿠키 읽기와 네트워크 규칙을 그 주소에 적용하고, 그 주소에 조회를 보내며, 방송 화면 안에 스크립트를 붙인다 | 전체 |

- 접근하는 주소 목록은 플랫폼이 정한 값이라 [치지직](../Development-Viewpoint/Platforms/Chzzk.md#12-주소-형식) · [SOOP](../Development-Viewpoint/Platforms/Soop.md)에 둔다.
