# Changelog

## 본문

### v3.0.0 (현재 배포 버전)

**화면 배치를 직접 구성하는 방식으로 전면 개편**

- 미리 정해진 배치 4종(기본형/반전형/서브하단/서브상단) 중 고르던 방식을 없애고, 화면을 원하는 대로 나눠 쓰도록 바꿈
- 메인 화면과 서브 화면 구분을 없앰. 모든 채널이 같은 크기의 칸 하나를 차지하고, 원하는 칸만 크게 키워서 볼 수 있음
- 칸 사이 경계를 끌어 크기 조절
- 칸 오른쪽 위의 손잡이를 잡아 다른 칸 가운데에 놓으면 자리 교환, 가장자리에 놓으면 그 칸이 갈라지면서 들어감
- 구성한 배치가 저장되어 다시 열어도 그대로 유지되고, 창 크기를 바꿔도 비율이 유지됨
- 서브 영역을 화면의 40%까지만 넓힐 수 있던 제한이 사라짐

**그 밖의 변화**

- 자리를 바꿔도 방송이 끊기지 않음. 예전에는 메인과 서브를 교환할 때마다 화면을 다시 불러와 잠시 멈추고 소리·화면 크기가 풀렸음
- 팝업에서 채널 순서만 바꿔도 모든 방송이 다시 불러와지던 문제 해소
- 소리를 방송 화면 안의 볼륨 조절로 직접 다루도록 바꿈. 채널마다 마지막에 쓰던 크기로 시작함
- 대시보드 채팅 기능 제거
- 팝업에서 메인 화면 지정과 목록 순서 변경 제거. 화면상의 자리는 대시보드가 기억함
- 팝업 시청 목록에 즐겨찾기 별 버튼 추가 (등록 전용, 해제는 즐겨찾기 목록에서)
- 팝업 시청 목록에 생방송 여부(LIVE/OFF) 표시 추가
- 시청 채널이 6개 이상이면 네트워크 환경에 따라 버퍼링이 생길 수 있다는 안내 표시
- 즐겨찾기에서 채널을 지워도 시청 목록의 즐겨찾기 표시가 그대로 남던 문제 수정
