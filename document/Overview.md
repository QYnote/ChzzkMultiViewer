## 본문

### 무엇을 하는 프로그램인가

치지직·SOOP의 여러 스트리머를 **한 화면에서 동시에** 본다. 메인 화면 1개와 서브 화면 여러 개를 함께 띄우고, 보고 싶은 방송을 메인으로 올려 가며 시청한다.

### 두 개의 화면

조작은 두 곳에서 이루어진다.

| 화면 | 여는 법 | 여기서 하는 일 |
|---|---|---|
| [팝업](PopupScreen.md) | 브라우저 툴바의 확장 아이콘 클릭 | 볼 스트리머를 고르고, 즐겨찾기로 정리하고, 설정을 바꾼다 |
| [대시보드](DashboardScreen.md) | 팝업에서 `멀티뷰 대시보드 열기` | 실제로 방송을 본다. 메인을 바꾸고 소리와 크기를 조절한다 |

팝업에서 정한 내용이 대시보드에 반영되고, 대시보드에서 메인을 바꾸면 그 결과가 다시 팝업 목록에 남는다.

### 할 수 있는 일

| 하고 싶은 것 | 어디서 |
|---|---|
| 볼 스트리머 고르기 — 팔로잉 목록에서 또는 직접 입력 | [팝업](PopupScreen.md#스트리머-추가하기) |
| 자주 보는 채널을 폴더로 정리 | [팝업](PopupScreen.md#즐겨찾기-다루기) |
| 메인으로 볼 채널 정하기 | [팝업](PopupScreen.md#시청-목록-다루기) · [대시보드](DashboardScreen.md#화면-조작하기) |
| 화면 배치 고르기 (4종) | [팝업](PopupScreen.md#설정-바꾸기) |
| 서브 채널 소리 켜고 크기 맞추기 | [대시보드](DashboardScreen.md#소리-다루기) |
| 방송이 밀렸을 때 자동으로 따라잡기 | [팝업](PopupScreen.md#설정-바꾸기)에서 켜고, [대시보드](DashboardScreen.md#자동으로-처리되는-것)가 실행 |

### 알아두면 좋은 것

- 팔로잉 목록 연동과 자동 로그인은 **해당 플랫폼에 로그인된 상태**에서만 동작한다.
- 서브 화면은 기본적으로 음소거이고, 소리는 채널마다 따로 기억된다.
- 넓은 화면 전환·광고 건너뛰기·방송 딜레이 따라잡기는 **자동으로** 처리된다.
- 지원 플랫폼별 채널 ID 형식 등은 [치지직](Chzzk.md) · [SOOP](Soop.md) 참고.
