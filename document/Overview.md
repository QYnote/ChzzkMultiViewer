## 본문

### 팝업

탭은 2단이다. 상위 탭이 `시청목록` · `기타설정` 2개이고, `시청목록` 탭 안에 `대시보드 표시 목록` · `스트리머 추가` 서브탭이 들어 있다.

**시청목록 탭 › 대시보드 표시 목록**

- 멀티뷰 목록(좌) + 즐겨찾기(우) 좌우 배치
- 멀티뷰 목록
  - 시청 중인 스트리머를 닉네임과 플랫폼 아이콘으로 표시
  - 메인 화면 1개는 상단 `📌 메인 화면` 박스에, 서브 채널은 그 아래 목록에 표시
    - `📌 메인 화면` 박스에 있는 스트리머가 대시보드의 메인 화면으로 사용됨
  - 서브 채널 순서 변경: 드래그 또는 위/아래 버튼
    - 맨 위 서브 채널은 더 위로 이동할 수 없음
  - 서브 채널을 메인 박스로 드래그하면 메인 교체
  - 항목 메뉴(⋯)
    - 메인으로 지정 — 메인 박스로 드래그하는 것과 동일 동작, 이미 메인인 항목에서는 비활성
    - 즐겨찾기 추가 — 이미 즐겨찾기에 있으면 메뉴에 나타나지 않음
  - 개별 삭제
- 즐겨찾기 보관함
  - 플랫폼 아이콘 및 LIVE/OFF 배지 표시
  - 폴더(트리) 구조로 분류, 깊이 제한 없음
    - `+ 폴더 추가`로 최상위 폴더 생성, 각 폴더의 `+ 폴더`로 하위 폴더 추가
    - 폴더 이름을 3번 연속 클릭하면 이름 변경 (Enter 또는 다른 곳 클릭 시 저장, Esc로 취소)
    - 폴더 옆 화살표(▶/▼)로 접기/펼치기
    - 하위 항목이 있는 폴더를 삭제하면 확인 창이 뜨고, 확인 시 하위 항목까지 일괄 삭제
    - 팔로잉 목록이나 시청 목록에서 즐겨찾기에 추가하면 최상위에 들어감
  - 드래그앤드롭으로 항목/폴더 순서 변경 및 이동
    - 항목: 같은 폴더 안 순서 변경, 다른 폴더 헤더에 드롭하면 그 폴더로 이동
    - 폴더: 헤더를 드래그해 같은 레벨끼리 순서 변경
    - `+ 폴더 추가` 버튼 위에 드롭하면 최상위로 이동
  - 시청 목록으로 복사 가능 (원본 유지, 중복 추가 방지)
  - 시청 목록과는 독립된 저장 공간 — 한쪽 삭제가 다른 쪽에 영향 없음
- `멀티뷰 대시보드 열기`
  - 열려 있지 않으면 새 탭으로 열기
  - 이미 열려 있으면 새 탭을 만들지 않고 기존 탭으로 이동하며 변경된 시청 목록을 자동 반영

**시청목록 탭 › 스트리머 추가**

- 치지직 / SOOP 플랫폼 탭으로 한 단계 더 구분
- 팔로잉 목록 연동
  - 로그인 여부에 따라 안내 문구 또는 `내 팔로잉 목록 불러오기` 버튼 표시
    - 치지직: 네이버 로그인 흔적이 남아 있는지만 확인
      ⚠️ 이 흔적은 네이버 전체에서 공통으로 쓰이는 것이라, 치지직에 한 번도 들어간 적이 없어도 네이버에만 로그인돼 있으면 "로그인됨"으로 인식됨
    - SOOP: 실제로 즐겨찾기 정보를 요청해 정상 응답이 오는지로 확인하므로 위와 같은 오인식이 없음
  - 목록을 불러오지 못하면(세션 만료 등) 실패 안내와 함께 해당 플랫폼 홈으로 이동하는 링크 표시
  - 불러온 목록은 LIVE 방송 우선 정렬, LIVE/OFF 배지 표시
  - 각 항목에서 즐겨찾기 추가 / 시청 목록 추가
    - 이미 즐겨찾기에 있는 채널은 노란색 버튼(비활성), 없는 채널은 회색 버튼
    - 이미 시청 목록에 있는 채널은 "추가됨" 버튼(비활성)
- 직접 추가
  - `채널 고유 ID`와 `스트리머 이름`을 각각 입력
    - 치지직: 정확히 32자리 영문/숫자
    - SOOP: 영문/숫자 조합 채널 ID (방송 URL에서 확인)
  - 입력 시 특수문자 사용 제한 및 형식 검증
  - 이미 등록된 채널은 중복 추가 방지 (시청 목록 기준)

**기타설정 탭**

- 서브채널 정보 표시 방식 선택 (항상 표시 / 마우스 올릴 때 × 프로필 사진 / 채널 이름)
- 대시보드 레이아웃 선택 (기본형 / 반전형 / 서브하단 / 서브상단)
- 자동 동기화 켜기/끄기 및 허용 지연 시간(초) 설정
  - 처음 설치했을 때 자동 동기화는 켜져 있고, 허용 지연 시간은 10초다
  - 설정 변경은 즉시 저장되며, 대시보드가 열려 있어도 새로고침 없이 바로 적용됨
- 현재 버전 정보 및 GitHub / X(Twitter) 링크

**공통**

- 작업 결과를 화면 하단 알림 메시지로 표시
  - 약 2.5초 후 자동 소멸, 새 알림이 뜨면 이전 알림은 즉시 교체

### 대시보드 공통

```
┌──────────────┬──────────────────────────────┬──────────────┐
│  서브 채널    │        메인 플레이어           │    채팅      │
│              │                              │              │
│  [서브타일]   │   영상 (재로드 없이 스왑)      │  채팅 iframe  │
│  [서브타일]   │                              │              │
│  [서브타일]   │  🔴 스트리머명  [↻ 새로고침]   │              │
└──────────────┴──────────────────────────────┴──────────────┘
```

레이아웃 4종(기본형/반전형/서브하단/서브상단)은 서브 채널 영역의 위치만 바뀌며, 메인/채팅 영역 구성은 동일하다.

- 메인 1채널 + 서브 N채널 동시 시청
- 팝업에서 변경한 시청 목록/레이아웃은 대시보드 새로고침 시 반영
- 메인 ↔ 서브 스왑: 서브 화면을 클릭하면 영상을 다시 불러오지 않고 표시 위치만 교체
  - 재로드가 없으므로 스왑 후에도 영상이 끊기지 않고 이어짐
  - 교체 결과는 시청 목록에 저장됨 — 팝업의 메인 화면도 함께 바뀌고, 대시보드를 새로고침해도 유지됨
- 방송 딜레이 표시: 메인은 하단 바에 항상, 서브는 마우스를 올릴 때
  - 딜레이는 영상의 현재 재생 위치와 실시간 송출 위치의 차이를 1초 간격으로 계산한 값
- 메인 화면만 새로고침하는 버튼 제공
- 비방송 안내: 생방송 중이 아니면 "방송중이 아닙니다" 표시, 자동 새로고침 중단 (1분마다 재확인 후 방송 재개 시 자동 복귀)
  - 비방송 상태인 화면은 자동 동기화 대상에서도 제외됨
- 초기화 안내: 화면을 새로 불러올 때(최초 진입/새로고침/메인↔서브 교체) 표시, 와이드 전환이 끝나면 소멸
  - 방송 중이 아닌 채널은 "방송중이 아닙니다" 표시와 함께 안내가 즉시 소멸
  - 1분 내 전환이 안 되면 "수동 최대화 필요" 안내로 전환 — 영상 위에서 와이드 단축키(T)를 직접 누른 뒤 안내를 클릭하거나, 안내의 새로고침 버튼으로 재시도
  - "초기화 진행중" 안내는 전환 완료 신호가 오지 않아도 65초가 지나면 자동 소멸 (안전장치)
  - "수동 최대화 필요" 안내에는 자동 소멸이 없어, 사용자가 안내를 클릭하거나 새로고침 버튼을 눌러야 사라짐
  ⚠️ 안내가 떠 있는 동안에는 메인↔서브 교환이 동작하지 않음
- 와이드 모드 자동 전환: 영상 재생 시작 시 자동 전환 시도
  - 전환이 확인되지 않으면 최대 1분간 반복 시도
  - 메인/서브 화면 모두 동일하게 적용되며, 메인↔서브 교체 시에도 양쪽 다시 시도
- 광고 자동 건너뛰기: 광고가 재생되면 스킵 버튼이 나타나는 즉시 자동으로 눌러 건너뜀 (치지직·SOOP 공통, 광고 하나당 한 번만 시도)
- SOOP 화면 전용 처리
  - 고화질 스트리머 연결 안내 팝업이 뜨면 자동으로 닫음
  - 고화질 플레이어가 로컬 앱이 설치돼 있는지 확인하려고 보내는 요청을 막음 — 로컬 앱이 없는 것으로 판단되어 일반 재생 방식으로 자동 전환되고, 그 결과 브라우저 권한 팝업이 뜨지 않음
- 자동 동기화: 메인 화면과 각 서브 화면에 개별 적용
  - 딜레이가 기준치를 넘으면 해당 화면만 새로고침
    - 새로고침 후 15초 동안은 같은 화면이 다시 새로고침되지 않음 (과도한 재시도 방지)
  - 영상 신호가 없으면 약 10초 후 해당 화면만 재시도
  - 광고가 재생 중인 화면은 새로고침 대상에서 제외됨 (광고 때문에 딜레이가 커지거나 신호가 끊긴 것으로 오인해 새로고침하는 것을 방지)
  - 켜기/끄기와 허용 지연 시간은 기타설정 탭의 설정 하나로 메인/서브 전체에 공통 적용

### 대시보드 메인 채널

- 메인 스트리머 채팅창 자동 표시 (숨김 상태 저장/복원)
  - 메인 채널이 바뀌어도 보이기/숨기기 상태는 그대로 유지
  - SOOP은 채팅 미지원으로 자동 숨김
- 영상 위 채팅 패널은 자동으로 접힌 상태로 표시

### 대시보드 서브 채널

- 기본 음소거 상태, 화면별 음소거 토글 + 볼륨 슬라이더로 개별 조절
- 메인과 교체되면 기존 메인의 볼륨 수준을 이어받음
  - 교체 직후뿐 아니라 0.5초·1.5초 후에도 한 번씩 더 적용해, 영상 로딩 타이밍 차이로 볼륨이 누락되는 것을 방지
- 마우스를 올리면 개별 삭제(✕)·새로고침 버튼 표시
  - 방송 중이 아닌 채널은 마우스를 올리지 않아도 ✕ 버튼이 항상 표시
  - 새로고침하면 해당 화면은 음소거 상태, 볼륨 50%로 초기화
- 서브 채널 영역 전체 접기/펼치기
  - 접힘 상태는 저장되어 다음에 열 때도 유지되며, 레이아웃 4종이 하나의 값을 함께 쓴다
- 서브하단/서브상단 레이아웃: 핸들 드래그로 영역 높이 조절
  - 조절한 높이는 저장되어 다음에 열 때도 유지되며, 서브하단과 서브상단이 하나의 값을 함께 쓴다 (한쪽에서 바꾸면 다른 쪽에도 그대로 적용됨)
  - 서브 목록 위에서 마우스 휠을 굴리면 목록이 좌우로 스크롤됨
- 기본형/반전형 레이아웃: 핸들 드래그로 영역 너비 조절
  - 조절한 너비는 저장되지 않아 대시보드를 다시 열면 초기 너비로 돌아감 (높이와 달리 유지되지 않음)
  ⚠️ 화면 전체 너비의 40%까지만 확장 가능 — 그 이상 넓히면 발생하는 스크롤을 없애는 방법을 아직 찾지 못해 제한해둠
- 서브 화면 좌측 상단에 프로필 사진 또는 채널 이름 표시
  - 표시 방식 4가지 중 선택 (항상 표시 / 마우스 올릴 때 × 프로필 사진 / 채널 이름), 기본값은 "마우스 올릴 때 (채널 이름)"
  - 프로필 사진 크기는 서브 화면 높이의 1/4과 사진 원본 크기 중 작은 값으로 자동 조절되며, 화면 크기가 바뀌면 함께 변함
  - 메인 화면과 자리를 교체해도 해당 자리의 채널에 맞는 표시로 함께 바뀜
- 서브 화면 영역 확대: 버튼 클릭 후 드래그로 원하는 영역만 확대해서 보고, 버튼으로 원래 화면으로 복원 가능
