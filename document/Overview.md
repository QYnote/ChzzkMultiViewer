# 개요

> **다루는 내용:** 무엇을 하는 프로그램인가 — 목적 · 범위 · 사용자 · 용어
> **갱신 트리거:** 목적이나 범위, 지원 플랫폼, 용어가 바뀔 때

## 본문

### 목적

치지직·SOOP의 여러 스트리머를 **한 화면에서 동시에** 본다. 채널마다 칸을 하나씩 주고, 그 칸들을 원하는 모양으로 나눠 배치해 시청한다. 모든 칸이 동등하며 주·보조 구분이 없다.

### 범위

| 하는 것 | 하지 않는 것 |
|---|---|
| 볼 채널을 정하고, 모아 두고, 조합째 보관하고 주고받기 | 방송 송출, 녹화, 다시 보기 |
| 여러 방송을 칸으로 나눠 동시에 보기 | 칸마다 소리를 따로 조절하기 — 방송 화면 안의 조절 기능에 맡긴다 |
| 넓은 화면 전환·광고 건너뛰기·딜레이 따라잡기 같은 반복 조작 대신 해 주기 | 채팅 기능 |
| 치지직 · SOOP 지원 | 그 밖의 플랫폼 (트위치 지원은 예정 — 최상위 [README](../README.md#업데이트-예정-기능)) |

### 사용자

- 치지직·SOOP 방송을 여러 개 동시에 보려는 시청자
- 팔로잉 목록 불러오기와 로그인 상태 시청은 **그 플랫폼에 로그인한 사용자**만 쓸 수 있다. 로그인하지 않아도 채널을 직접 넣어 볼 수는 있다
- 웹 개발 지식을 가정하지 않는다

### 두 개의 화면

| 화면 | 여는 법 | 여기서 하는 일 |
|---|---|---|
| 팝업 | 브라우저 툴바의 확장 아이콘 클릭 | 볼 채널을 고르고, 즐겨찾기로 정리하고, 조합을 보관하고, 설정을 바꾼다 |
| 대시보드 | 팝업에서 `멀티뷰 대시보드 열기` | 실제로 방송을 본다. 칸을 나누고 크기와 자리를 조절한다 |

### 용어

| 용어 | 뜻 |
|---|---|
| 시청 목록 | 대시보드에 띄울 채널들. 팝업 왼쪽 칸 `멀티뷰 표시 목록`에 보인다 |
| 칸 | 대시보드에서 채널 하나가 차지하는 사각형 |
| 방송 화면 | 칸 안에 띄운 플랫폼의 방송 페이지 |
| 즐겨찾기 | 채널을 하나하나 폴더로 모아 두는 곳. 시청 목록과 별개다 |
| 저장된 목록 | 시청 목록 한 벌을 이름 붙여 보관한 것 |
| 공유 글 | 시청 목록 한 벌을 남에게 보내려고 글로 만든 것 |
| 넓은 화면 | 방송 페이지의 채팅·주변 영역을 접고 영상을 크게 보여 주는 플랫폼 기능 |
| 딜레이 | 방송이 실제로 진행된 지점과 내 화면이 재생 중인 지점의 차이 |
| 자동 동기화 | 딜레이가 기준을 넘거나 영상 신호가 끊긴 칸을 저절로 다시 읽는 것 |
| 끼워 넣기 제한 | 플랫폼이 자기 페이지를 다른 페이지 안에 넣지 못하게 막는 보안 규칙 |
