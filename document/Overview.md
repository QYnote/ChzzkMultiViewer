## 본문

### 무엇을 하는 프로그램인가

치지직·SOOP의 여러 스트리머를 **한 화면에서 동시에** 본다. 채널마다 칸을 하나씩 주고, 그 칸들을 원하는 모양으로 나눠 배치해 시청한다. 모든 채널이 동등하며 주·보조 구분이 없다.

### 두 개의 화면

조작은 두 곳에서 이루어진다.

| 화면 | 여는 법 | 여기서 하는 일 |
|---|---|---|
| [팝업](PopupScreen.md) | 브라우저 툴바의 확장 아이콘 클릭 | 볼 스트리머를 고르고, 즐겨찾기로 정리하고, 설정을 바꾼다 |
| [대시보드](DashboardScreen.md) | 팝업에서 `멀티뷰 대시보드 열기` | 실제로 방송을 본다. 칸을 나누고 크기와 자리를 조절한다 |

팝업에서 볼 채널을 정하면 대시보드에 반영된다. 화면상의 자리는 대시보드가 채널마다 따로 기억하므로, 팝업 목록의 순서는 화면에 영향을 주지 않는다.

### 할 수 있는 일

| 하고 싶은 것 | 어디서 |
|---|---|
| 볼 스트리머 고르기 — 팔로잉 목록에서 또는 직접 입력 | [팝업](PopupScreen.md#13-스트리머-추가하기) |
| 자주 보는 채널을 폴더로 정리 | [팝업](PopupScreen.md#12-즐겨찾기-다루기) |
| 화면을 원하는 모양으로 나누기 | [대시보드](DashboardScreen.md#11-화면-배치) |
| 칸 크기 조절하고 자리 바꾸기 | [대시보드](DashboardScreen.md#21-화면-조작하기) |
| 방송이 밀렸을 때 자동으로 따라잡기 | [팝업](PopupScreen.md#21-설정-바꾸기)에서 켜고, [대시보드](DashboardScreen.md#32-자동으로-처리되는-것)가 실행 |

### 알아두면 좋은 것

- 팔로잉 목록 연동과 자동 로그인은 **해당 플랫폼에 로그인된 상태**에서만 동작한다.
- 소리는 방송 화면 안의 조절 기능을 그대로 쓴다. 채널마다 마지막에 쓰던 크기로 시작한다.
- 넓은 화면 전환·광고 건너뛰기·방송 딜레이 따라잡기는 **자동으로** 처리된다.
- 지원 플랫폼별 채널 ID 형식 등은 [치지직](Chzzk.md) · [SOOP](Soop.md) 참고.
