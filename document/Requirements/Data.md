# 데이터

> **다루는 내용:** 브라우저 저장소에 남기는 데이터의 종류·모양·의미, 데이터끼리의 관계
> **갱신 트리거:** 저장하는 데이터의 종류나 모양, 의미가 바뀔 때

## 본문

### 저장 위치

확장 프로그램 전용 **브라우저 로컬 저장소**에 둔다. 기기 밖으로 나가지 않고 다른 기기와 동기화하지 않는다. 브라우저 프로필마다 따로 있다.

### 저장 항목

| 저장 항목 | 무엇 | 쓰는 쪽 | 읽는 쪽 |
|---|---|---|---|
| [시청 목록](#1-시청-목록) | 대시보드에 띄울 채널들 | 팝업 · 대시보드(칸을 닫을 때) | 팝업 · 대시보드 |
| [즐겨찾기 트리](#2-즐겨찾기-트리) | 폴더로 모아 둔 채널 | 팝업 | 팝업 |
| [예전 형식 즐겨찾기](#2-즐겨찾기-트리) | 옛 버전이 남긴 평평한 목록 | 없음 | 팝업 (트리가 없을 때 한 번) |
| [저장된 목록](#3-저장된-목록) | 이름 붙여 보관한 시청 목록 여러 벌 | 팝업 | 팝업 |
| [시스템 설정](#4-시스템-설정) | 자동 동기화 · 허용 지연 시간 · 칸 채널 표시 방식 | 팝업 | 팝업 · 대시보드 |
| [대시보드 배치](#5-대시보드-배치) | 칸을 나눈 구조와 비율 | 대시보드 | 대시보드 |

### 0. 채널 하나를 나타내는 값

시청 목록 · 즐겨찾기 · 저장된 목록이 모두 같은 모양으로 채널을 담는다.

| 항목 | 뜻 |
|---|---|
| 채널 고유 ID | 플랫폼이 정한 값. 형식은 [치지직](External-Interfaces/Chzzk.md#11-채널-id) · [SOOP](External-Interfaces/Soop.md#11-채널-id) 참고 |
| 이름 | 담을 때의 닉네임. 스트리머가 이름을 바꿔도 갱신하지 않는다 |
| 플랫폼 | 치지직 또는 SOOP. **값이 없으면 치지직으로 본다** |

### 1. 시청 목록

채널 값의 목록이다. 같은 채널은 한 번만 담긴다.

- **순서는 첫 배치를 자동으로 만들 때만 쓴다.** 그 뒤 화면상의 자리는 [대시보드 배치](#5-대시보드-배치)가 기억하므로 순서를 바꿔도 화면은 그대로다.
- 대시보드는 이 값이 바뀌는 것을 **감시하지 않는다.** 팝업에서 `멀티뷰 대시보드 열기`를 누를 때만 반영한다 — [대시보드에 반영](Functions/Channel-Selection.md#4-대시보드에-반영)

### 2. 즐겨찾기 트리

맨 위 폴더 하나에서 시작하는 폴더 트리다. 깊이 제한이 없다.

| 폴더가 담는 것 | 뜻 |
|---|---|
| 고유 식별값 | 이름이 같은 폴더도 구분한다 |
| 이름 | 사용자가 정한 이름 |
| 채널 목록 | 이 폴더에 바로 들어 있는 채널 값들. 순서가 화면 순서다 |
| 하위 폴더 목록 | 순서가 화면 순서다 |
| 접힘 여부 | 접어 둔 상태를 기억한다 |

- 같은 채널은 **트리 전체에서 한 번만** 담긴다.
- 예전 형식 즐겨찾기는 트리가 아직 없을 때 한 번 읽어 **맨 위 폴더의 채널로 옮긴다.** 플랫폼 값은 옮기지 않으므로 옮긴 채널은 치지직으로 간주된다. 예전 값은 지우지 않고 남겨 둔다.

### 3. 저장된 목록

이름 붙인 시청 목록 여러 벌이다. 한 벌은 **이름과 채널 값 목록**만 담는다.

- 이름은 겹치지 않는다. 같은 이름으로 저장하면 덮어쓰고, 이름을 바꿀 때 겹치면 바꾸지 않는다.
- 저장 당시의 닉네임을 그대로 담는다.
- 화면 배치는 담지 않는다.

### 4. 시스템 설정

| 값 | 기본값 |
|---|---|
| 자동 동기화 켜짐 여부 | 켜짐 |
| 허용 지연 시간 (초, 정수) | 10 — 숫자가 아니면 10으로 둔다 |
| 방송 칸 채널 표시 방식 | 마우스 올릴 때 · 채널 이름 |

고를 수 있는 값과 화면에서 바꾸는 방법은 [설정](Functions/Settings.md) 참고.

- 예전 버전의 표시 방식 값은 읽을 때 지금 체계로 바꾼다 — "항상" → 항상·프로필 사진, "마우스 올릴 때" → 마우스 올릴 때·프로필 사진, "표시 안 함" → 마우스 올릴 때·채널 이름.
- 대시보드는 이 값의 변경을 **감시해서** 새로고침 없이 바로 반영한다. 저장 항목 중 대시보드가 감시하는 것은 이것뿐이다.

### 5. 대시보드 배치

칸을 재귀적으로 나눈 **트리 하나**다. 칸은 두 종류다.

| 칸 | 담는 것 |
|---|---|
| 나눔 칸 | 나누는 방향(좌우 / 위아래), 자식 칸들, 자식마다의 비율(합이 1) |
| 방송 칸 | 채널 고유 ID |

- **비율로 저장**하므로 창 크기가 바뀌어도 배치가 유지된다.
- "채널마다 자리를 기억한다"는 것은 트리 안에서 그 채널의 방송 칸이 있는 위치를 뜻한다. 채널마다 따로 저장되는 값이 있는 것은 아니다.
- 읽은 값이 이 모양이 아니면 버리고 새로 만든다. 저장소가 손상되었거나 옛 버전 값이 남아 있을 때 화면이 깨지지 않게 하기 위해서다.
- 칸 안의 영역 확대 상태는 **저장하지 않는다.** 대시보드를 다시 열면 풀린다.

### 데이터끼리의 관계

저장 항목은 서로 독립적이다. 한쪽을 지워도 다른 쪽을 자동으로 지우지 않는다.

| 상황 | 결과 |
|---|---|
| 시청 목록에서 채널을 뺌 | 즐겨찾기·저장된 목록은 그대로. 배치에서는 대시보드가 다음에 목록을 읽을 때 그 칸을 빼고, 옆 칸이 자리를 흡수한다 |
| 시청 목록에 새 채널이 들어옴 | 배치에 없던 채널은 대시보드가 다음에 목록을 읽을 때 기존 배치에 끼워 넣는다 |
| 배치가 아예 없음 | 시청 목록 순서로 자동 배치를 만든다 |
| 대시보드에서 마지막 칸을 닫음 | 배치를 지운다 |
| 즐겨찾기에서 채널을 뺌 | 시청 목록은 그대로 |
| 저장된 목록을 불러옴 | 시청 목록을 통째로 바꾼다. 저장된 목록 자체는 그대로 |
