# 품질 속성

> **다루는 내용:** 기능 하나에 속하지 않고 여러 기능에 걸친 동작 방식의 요구
> **갱신 트리거:** 끊김·보안·데이터 보호·호환성에 관한 요구가 바뀔 때

## 본문

### 1. 시청이 끊기지 않음

보던 방송은 **사용자가 바란 경우가 아니면 다시 읽지 않는다.** 다시 읽으면 영상이 끊기고 넓은 화면·음소거 같은 방송 페이지 상태도 풀린다.

| 상황 | 요구 |
|---|---|
| 팝업에서 시청 목록을 바꿈 | 대시보드를 열기 전까지 방송 화면을 건드리지 않는다 — [대시보드에 반영](Functions/Channel-Selection.md#4-대시보드에-반영) |
| 대시보드를 열었는데 담긴 채널이 같음 | 아무것도 다시 읽지 않는다 |
| 칸 크기 조절·자리 바꾸기·쪼개기 | 방송 화면을 다시 읽지 않는다 — [칸 배치](Functions/Multiview/Layout.md#3-배치-바꾸기) |
| 설정을 바꿈 | 새로고침 없이 반영한다 |
| 막 열린 칸 | 잘못 잰 딜레이로 다시 읽지 않는다 — [자동 동기화](Functions/Multiview/Automation.md#3-자동-동기화) |

### 2. 보안

| 요구 | 까닭 |
|---|---|
| 끼워 넣기 제한은 **대시보드가 띄운 방송 화면에서만** 푼다 | 이 제한은 다른 사이트가 방송 페이지를 몰래 덮어씌워 클릭을 가로채는 공격을 막는다. 전체에서 풀면 사용자가 다른 사이트에서 그 보호를 잃는다 |
| 로그인 쿠키는 **해당 플랫폼 주소로 가는 요청에만** 싣는다 | 다른 곳으로 로그인 정보가 새지 않게 한다 |
| 받는 권한을 [제약](Constraints.md#2-설치-때-받는-권한)의 목록으로 한정한다 | 필요 없는 권한을 받지 않는다 |

### 3. 데이터 보호

- 저장하는 데이터는 사용자 기기의 브라우저 안에만 둔다. 외부 서버로 보내지 않는다 — [데이터](Data.md#저장-위치)
- 저장 항목끼리는 독립적이다. 한쪽을 지워도 다른 쪽을 자동으로 지우지 않는다.

### 4. 예전 버전과의 호환

| 상황 | 요구 |
|---|---|
| 예전 버전이 남긴 즐겨찾기 | 트리로 옮겨 읽는다 |
| 예전 버전의 설정 값 | 지금 체계로 바꿔 읽는다 |
| 플랫폼 값이 없는 채널 | 치지직으로 본다 |
| 저장된 배치가 깨져 있음 | 쓰지 않고 새로 만든다. 화면이 깨지지 않게 한다 |
| 예전 형식의 공유 글 | 채널은 모두 읽는다 |

자세한 규칙은 [데이터](Data.md) · [공유 글](Functions/Saved-Lists.md#2-공유-글) 참고.
