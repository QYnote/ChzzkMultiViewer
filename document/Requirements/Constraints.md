# 제약

> **다루는 내용:** 설계를 고를 때 반드시 지켜야 하는 외부 조건
> **갱신 트리거:** 지켜야 하는 조건이 생기거나 없어질 때, 받는 권한을 더하거나 뺄 때

## 본문

### 1. 공식 기능을 쓰지 않음

플랫폼의 공식 개발자 기능을 쓰지 않는다. **브라우저에 남은 로그인 세션**으로 플랫폼의 내부 조회 주소를 부르고, 방송 페이지 화면을 직접 다룬다.[^1]

- 그래서 플랫폼이 내부 조회 주소나 응답 모양, 쿠키, 방송 페이지의 화면 구조를 바꾸면 그 기능이 멈출 수 있다. 미리 알려 주지 않는다.
- 플랫폼마다 기대는 값은 [치지직](External-Interfaces/Chzzk.md) · [SOOP](External-Interfaces/Soop.md)에 모아 둔다. 기능이 멈추면 여기부터 확인한다.

### 2. 설치 때 받는 권한

크롬 브라우저 확장 프로그램으로 동작한다. 권한은 설치할 때 한 번에 받고, 쓰는 도중에 따로 묻지 않는다. 받는 권한은 아래뿐이다.

| 권한 | 왜 필요한가 |
|---|---|
| 브라우저 저장소 | 시청 목록·즐겨찾기·저장된 목록·설정·배치를 보관한다 — [데이터](Data.md) |
| 탭 조회 | 이미 열린 대시보드 탭을 찾아 그리로 옮겨 가고 변경을 알린다 |
| 네트워크 규칙 | 방송 화면과 조회 요청에 로그인 쿠키를 싣는다. 대시보드가 띄운 방송 화면에서 끼워 넣기 제한을 걷어 낸다 |
| 쿠키 읽기 | 실어 보낼 로그인 쿠키를 읽는다. 치지직 로그인 여부를 판단한다 |
| 스크립트 등록 | SOOP 방송 페이지와 같은 실행 영역에 스크립트를 넣는다 — [SOOP](External-Interfaces/Soop.md#21-고화질-재생기) |
| 사이트 접근 — 치지직·네이버·SOOP | 위 일들을 그 주소에 적용하고, 그 주소에 조회를 보내며, 방송 화면 안에 스크립트를 붙인다 |

- 클립보드를 읽는 권한은 받지 않는다. 받은 공유 글은 입력창으로 받는다 — [공유 글](Functions/Saved-Lists.md#2-공유-글)

### 3. 브라우저가 나눠 놓은 실행 환경

확장 프로그램은 브라우저가 나눠 놓은 실행 환경 위에서 돈다. 환경끼리는 함수를 직접 불러 쓸 수 없고, **메시지나 저장소를 거쳐야만** 주고받는다.

| 실행 환경 | 브라우저가 정한 성질 |
|---|---|
| 배경 작업 | 화면이 없다. 할 일이 없으면 브라우저가 꺼 버려 값을 오래 들고 있지 못한다 |
| 팝업 | 툴바 아이콘을 누를 때 생기고 **닫는 순간 통째로 사라진다** |
| 대시보드 탭 | 닫기 전까지 산다 |
| 방송 페이지 안 | 남의 페이지에 얹혀 도는 격리된 환경. 그 페이지 화면만 만질 수 있다 |

- 브라우저는 확장 프로그램이 만든 화면에 **로그인 쿠키를 저절로 실어 주지 않는다.** 그래서 따로 실어 보내야 한다.

[^1]: 공식 개발자 기능은 신청·승인 절차와 사용량 제한이 있다. 사용자는 이미 플랫폼에 로그인해 있으므로 따로 인증할 필요가 없는 쪽을 택했다.
