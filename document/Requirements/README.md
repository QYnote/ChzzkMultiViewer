# 요구사항

> **다루는 내용:** 완성본이 무엇을 하는가. 요소 분해 트리와 요구사항 문서 목록
> **갱신 트리거:** 기능이 추가·제거되거나 요소 분해 트리가 바뀔 때

이 영역은 **무엇을** 하는지만 적는다. 무엇으로 만들었는지는 [구현](../Implementation/README.md)에 있다. 다른 언어·도구로 다시 만들어도 이 영역의 문장은 그대로 맞아야 한다.

## 요소 분해 트리

완성본이 하는 일을 큰 가지에서 작은 가지로 나눈 것이다. 문서를 어디에 둘지와 무엇이 중복인지를 이 트리로 판정한다.

```mermaid
graph LR
  R[MultiStream]

  R --> A[볼 채널 정하기]
  A --> A1[직접 추가]
  A --> A2[팔로잉에서 추가]
  A --> A3[시청 목록 다루기]
  A --> A4[대시보드에 반영]

  R --> B[채널 모아 두기]
  B --> B1[즐겨찾기 폴더]

  R --> C[조합 보관·주고받기]
  C --> C1[저장된 목록]
  C --> C2[공유 글]

  R --> D[여러 방송 동시 시청]
  D --> D1[방송 칸 띄우기]
  D --> D2[칸 배치]
  D --> D3[칸 조작]
  D --> D4[자동 처리]

  R --> E[설정]

  style R fill:#ffd966,stroke:#b8860b,color:#000
```
