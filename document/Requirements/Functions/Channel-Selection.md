# 볼 채널 정하기

> **다루는 내용:** 시청 목록에 채널을 넣고 빼는 일, 그 결과가 대시보드에 반영되는 시점
> **갱신 트리거:** 채널을 넣고 빼는 방법이나 대시보드 반영 시점이 바뀔 때

## 본문

시청 목록에 담긴 채널이 대시보드에 뜬다. 어느 채널이 어디에 놓일지는 대시보드가 기억하므로, 시청 목록의 순서는 화면에 영향을 주지 않는다.[^1]

### 1. 직접 추가

플랫폼(치지직·SOOP)을 고르고 `채널 고유 ID`와 `스트리머 이름`을 넣어 시청 목록에 더한다. 채널 ID 형식은 플랫폼마다 다르다 — [치지직](../External-Interfaces/Chzzk.md#11-채널-id) · [SOOP](../External-Interfaces/Soop.md#11-채널-id).

| 상황 | 기대 동작 |
|---|---|
| 형식에 맞는 새 채널 | 시청 목록에 더하고 알림을 띄운다 |
| 둘 중 하나라도 비어 있음 | 더하지 않고 알린다 |
| 치지직인데 ID가 32자리가 아님 | 더하지 않고 알린다 |
| SOOP인데 ID에 영문·숫자 외의 글자 | 더하지 않고 알린다 |
| 이름에 `< > " ' &`를 입력 | 그 글자를 지우고 알린다 |
| 이미 시청 목록에 있는 채널 | 더하지 않고 알린다 |

### 2. 팔로잉에서 추가

그 플랫폼에서 팔로잉한 채널 목록을 불러와 골라 넣는다. 로그인한 사용자만 쓸 수 있다.

| 상황 | 기대 동작 |
|---|---|
| 로그인 안 됨 | 불러오기 버튼 대신 로그인 안내와 플랫폼 로그인 링크를 보여 준다 |
| 불러오기 성공 | **방송 중인 채널이 위로** 오도록 정렬하고, 채널마다 방송 중 여부를 표시한다 |
| 불러오기 실패 (로그인 만료 등) | 실패 안내와 함께 그 플랫폼 첫 화면으로 가는 링크를 보여 준다 |
| 이미 시청 목록에 있는 채널 | "추가됨"으로 표시하고 더하기를 막는다 |
| 이미 즐겨찾기에 있는 채널 | 즐겨찾기 버튼을 채운 상태로 보여 준다 |
| 목록에서 즐겨찾기에 넣음 | 즐겨찾기의 맨 위 폴더에 넣는다 |

**주의**
- ⚠️ 치지직은 **네이버에만 로그인돼 있어도 로그인된 것으로 보인다.** SOOP은 이런 오인이 없다 — [치지직](../External-Interfaces/Chzzk.md#13-로그인-판단과-인증-쿠키)

### 3. 시청 목록 다루기

| 하고 싶은 것 | 기대 동작 |
|---|---|
| 채널 빼기 | 시청 목록에서 지운다. 즐겨찾기·저장된 목록은 그대로다 |
| 즐겨찾기에 넣기 | 즐겨찾기의 맨 위 폴더에 넣는다. 이미 있으면 버튼이 채워진 채 잠긴다. 빼기는 즐겨찾기에서 한다 |
| 지금 목록을 이름 붙여 저장 | [조합 보관](Saved-Lists.md#1-저장된-목록) 참고 |
| 채널이 6개 이상 | 네트워크 환경에 따라 버퍼링이 생길 수 있다는 안내를 목록 위에 띄운다 |

### 4. 대시보드에 반영

시청 목록을 어떻게 바꾸든 **열려 있는 대시보드는 그 자리에서 바뀌지 않는다.** `멀티뷰 대시보드 열기`를 누를 때 한 번에 반영한다.[^2]

| 상황 | 기대 동작 |
|---|---|
| 대시보드가 열려 있지 않음 | 새 탭으로 연다 |
| 이미 열려 있고 담긴 채널이 같음 | 그 탭으로 옮겨 가기만 한다. 아무것도 다시 읽지 않아 **보던 방송이 끊기지 않는다** |
| 이미 열려 있고 담긴 채널이 하나라도 다름 | 그 탭으로 옮겨 가며 **모든 칸을 다시 읽는다.** 겹치는 채널도 그 순간 함께 끊긴다 |
| 팝업에서 바꾸고 아직 열기를 누르지 않음 | 팝업과 대시보드가 서로 다른 내용을 보여 준다. 따로 알리지 않는다 |

- 대시보드에서 칸을 닫는 것은 대시보드 자신의 조작이라 그 자리에서 시청 목록에 반영한다 — [칸 조작](Multiview/Cell-Controls.md)

[^1]: 순서는 배치가 하나도 없을 때 자동 배치를 만드는 데만 쓰인다 — [칸 배치](Multiview/Layout.md#2-처음-열었을-때의-배치)
[^2]: 목록을 손보는 동안 보던 방송이 끊기지 않게 하려는 것이다. 탈락한 대안 — 바뀔 때마다 바로 반영하기. 목록을 갈아탈 때마다 모든 칸이 다시 읽혀 끊겼다.
