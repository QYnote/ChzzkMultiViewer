# 자동 처리

> **다루는 내용:** 사용자가 시키지 않아도 대시보드가 칸마다 대신 해 주는 일과 그때 띄우는 안내
> **갱신 트리거:** 자동으로 처리하는 일이나 그 조건·안내가 바뀔 때

## 본문

### 1. 넓은 화면 전환과 채팅 접기

| 상황 | 기대 동작 |
|---|---|
| 방송 영상이 재생을 시작함 | 잠시 뒤 넓은 화면으로 바꾼다. 확인될 때까지 약 18초간 다시 시도한다 |
| 약 18초 안에 바뀌지 않음 | "수동 최대화 필요" 안내를 띄운다 |
| 대시보드 탭이 보이지 않던 사이 전환이 안 됨 | 탭으로 돌아왔을 때 다시 시도한다 |
| 방송 페이지에 채팅이 펼쳐져 있음 | 접는다 |

### 2. 광고 건너뛰기

| 상황 | 기대 동작 |
|---|---|
| 건너뛰기 버튼이 나타남 | 바로 누른다. 광고 하나에 한 번만 시도한다 |
| 광고가 재생 중 | 그 칸은 자동 동기화에서 빠진다 |

### 3. 자동 동기화

설정에서 켜 두면 칸마다 따로 동작한다 — [설정](../Settings.md).

| 상황 | 기대 동작 |
|---|---|
| 딜레이가 허용 지연 시간을 넘음 | 그 칸만 다시 읽는다. 같은 칸은 15초 안에 또 다시 읽지 않는다 |
| 영상 신호가 10초 동안 없음 | 그 칸만 다시 읽는다 |
| 칸이 열린 뒤 10초 안에 재생이 시작되지 않음 | 신호 없음으로 보고 다시 읽는다 |
| 막 열린 칸, 아직 재생 전 | 딜레이를 재지 않는다. 열자마자 다시 읽는 일이 없다 |
| 광고 중이거나 방송이 꺼진 칸 | 판정에서 뺀다. 광고가 끝날 때까지는 신호 없음으로도 보지 않는다 |
| 설정에서 끔 | 어느 칸도 저절로 다시 읽지 않는다 |

- 딜레이는 재생이 시작된 뒤부터 잰다.[^1]

### 4. 화면에 나타나는 안내

| 안내 | 언제 | 언제 사라지나 |
|---|---|---|
| **초기화 진행중입니다** | 칸을 새로 읽을 때 | 넓은 화면 전환이 끝나거나 방송이 꺼진 것을 알았을 때. 늦어도 65초 뒤 |
| **수동 최대화 필요** | 약 18초 안에 넓은 화면 전환이 안 됐을 때 | 사용자가 안내를 누르거나 안내의 새로고침 버튼을 누를 때. **저절로 사라지지 않는다** |
| **방송중이 아닙니다** | 칸의 채널이 방송 중이 아닐 때 | 1분마다 다시 확인해 방송이 시작되면 |

### 5. SOOP 전용 처리

| 상황 | 기대 동작 |
|---|---|
| 고화질 연결 안내 창이 뜸 | 자동으로 닫는다 |
| 방송 화면이 내 컴퓨터의 로컬 앱을 찾으려 함 | 찾지 못하게 막아, 브라우저 권한 요청 창이 뜨지 않고 일반 재생으로 넘어가게 한다 — [SOOP](../../External-Interfaces/Soop.md#21-고화질-재생기) |

[^1]: 막 열린 칸은 재생 위치가 0인데 방송 끝 지점은 이미 수십 초 뒤라, 그때 재면 밀리지 않았는데도 수십 초로 나온다. 2026-10-07 진단에서 확인됐다. 탈락한 대안 — 처음 들어온 큰 값을 무시하기. 실제로 크게 밀린 경우까지 놓칠 수 있다.
