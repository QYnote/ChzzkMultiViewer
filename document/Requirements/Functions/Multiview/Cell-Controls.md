# 칸 조작

> **다루는 내용:** 칸 하나에 대해 사용자가 하는 조작과 칸에 표시되는 것
> **갱신 트리거:** 칸 조작 방법이나 칸 표시가 바뀔 때

## 본문

### 1. 칸 조작 줄

각 칸의 오른쪽 위에 조작이 모여 있다. 마우스를 올리면 나타나고, 방송이 꺼진 칸은 닫기 버튼이 늘 보인다. 화면 배치는 [사용자 화면](../../External-Interfaces/User-Interface.md#2-대시보드) 참고.

| 하고 싶은 것 | 기대 동작 |
|---|---|
| 그 칸만 새로고침 | 그 칸의 방송 화면만 다시 읽는다 |
| 그 칸 닫기 | 칸을 없애고 옆 칸이 자리를 흡수한다. **시청 목록에서도 바로 뺀다** |
| 화면 일부만 크게 보기 | 메뉴에서 확대를 고르고 영역을 끌어 고르면, 그 영역이 칸을 꽉 채우게 확대된다. 확대는 기억하지 않는다 |
| 자리 옮기기 | 손잡이 — [칸 배치](Layout.md#3-배치-바꾸기) |
| 딜레이 보기 | 마우스를 올리면 조작 줄에 지금 딜레이가 보인다 |

- 칸 아래쪽에는 아무것도 놓지 않는다. 방송 페이지가 자기 조작 막대를 그곳에 그리므로, **소리·전체화면 같은 방송 페이지 기능을 그대로 쓸 수 있다.**

### 2. 소리

이 프로그램은 음량을 **건드리지 않는다.** 소리는 방송 화면 안의 조절 기능으로 다룬다.[^1]

| 상황 | 기대 동작 |
|---|---|
| 방송 화면이 음소거 상태로 시작함 | 한 번 음소거를 풀어 준다. 음량 크기는 바꾸지 않는다 |
| 다시 연 채널 | 방송 페이지가 기억한, 그 채널에서 마지막에 쓰던 크기로 시작한다 |
| 처음 보는 채널 | 방송 페이지의 기본 크기로 시작한다 |

**주의**
- ⚠️ 여러 칸의 소리가 동시에 날 수 있다. 원하지 않는 칸은 그 방송 화면에서 직접 음소거한다.

### 3. 칸의 채널 표시

칸 왼쪽 위에 프로필 사진이나 채널 이름을 보여 준다. 표시 방식은 [설정](../Settings.md)에서 고른다.

| 표시 방식 | 기대 동작 |
|---|---|
| 항상 · 프로필 사진 | 프로필 사진이 늘 보인다 |
| 항상 · 채널 이름 | 채널 이름이 늘 보인다 |
| 마우스 올릴 때 · 프로필 사진 | 마우스를 올린 칸에만 프로필 사진이 보인다 |
| 마우스 올릴 때 · 채널 이름 | 마우스를 올린 칸에만 채널 이름이 보인다 |

- 프로필 사진 크기는 칸 높이의 1/4, 원본 크기, 정해진 상한 중 가장 작은 값이다. 칸 크기가 바뀌면 함께 바뀐다.

[^1]: 탈락한 대안 — 대시보드를 열 때 모든 방송을 소리 없이 시작하기. 한 번 만들었다가 되돌렸다. 치지직은 음량을 채널마다 기억하지만 SOOP은 전체를 하나로 기억해, 칸마다 따로 다룰 수 없었다. 음량 값을 덮어쓰는 방식은 방송 페이지가 그 값을 저장해 다시 열 때 보이는 크기와 실제 소리가 어긋나므로 어느 경우에도 쓸 수 없다.
