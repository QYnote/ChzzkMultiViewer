# 방송 칸 띄우기

> **다루는 내용:** 칸 안에 플랫폼의 방송 화면을 제대로 띄우는 일
> **갱신 트리거:** 방송 화면을 띄우는 방식이나 그때의 기대 동작이 바뀔 때

## 본문

### 1. 로그인 상태로 띄우기

플랫폼에 로그인해 있으면 칸 안의 방송 화면도 **로그인된 상태**로 뜬다.[^1]

| 상황 | 기대 동작 |
|---|---|
| 플랫폼에 로그인함 | 칸의 방송 화면이 로그인된 상태다 |
| 로그인하지 않음 | 칸의 방송 화면은 뜬다. 로그인 안 된 상태다 |
| 대시보드를 연 채 로그인·로그아웃함 | 그 뒤 새로 읽는 칸부터 바뀐 상태가 반영된다 |

### 2. 끼워 넣기 제한 대응

플랫폼이 다른 페이지 안에 자기 방송 화면을 넣지 못하게 막아도 **대시보드 칸에서는 뜬다.** 막히는 플랫폼과 제한 내용은 [치지직](../../External-Interfaces/Chzzk.md#15-다른-페이지-안에-끼워-넣기-제한) 참고.

| 상황 | 기대 동작 |
|---|---|
| 대시보드 칸에 치지직 방송 — 로그인 상태 | 방송이 뜬다. 로그인된 화면이다 |
| 대시보드 칸에 치지직 방송 — 로그아웃 상태 | 방송이 뜬다. 로그인 안 된 화면이다 |
| 치지직을 일반 탭으로 엶 | 달라지는 것이 없다 |
| 다른 웹사이트가 자기 페이지에 치지직을 끼워 넣음 | **지금처럼 막힌다** |
| 확장 설치·업데이트 직후, 브라우저를 다시 켠 직후 | 대시보드를 열면 바로 뜬다. 따로 할 일이 없다 |

- 제한을 푸는 범위는 [품질 속성 — 보안](../../Quality-Attributes.md#2-보안)에 따른다.

### 3. 좁은 칸 축소

칸이 플랫폼 방송 화면이 온전히 그려지는 폭보다 좁으면, **방송 화면 전체를 비율 그대로 줄여서** 칸에 맞춘다.[^2]

| 상황 | 기대 동작 |
|---|---|
| 칸이 그 폭보다 좁음 | 잘리거나 스크롤 막대가 생기지 않고, 화면 전체가 줄어 보인다 |
| 칸이 그 폭 이상 | 줄이지 않는다 |
| 줄어든 칸에서 영역 확대 | 확대가 이긴다. 확대를 풀면 다시 줄어든 상태로 돌아온다 |
| 줄어든 칸에서 확대 영역을 고름 | 눈에 보이는 화면에서 고른 영역이 그대로 확대된다 |

**주의**
- ⚠️ 기준보다 넓은 칸은 줄이지 않고 그리므로, 크기가 비슷한 칸끼리 화면 배치가 어긋나 보일 수 있다. 화면이 클수록 자주 나온다. 경계를 없애려면 칸 크기와 무관하게 늘 같은 폭으로 그려야 하는데, 그러면 큰 칸이 확대되어 흐릿해진다. 지금은 흐릿해지지 않는 쪽을 택했다.

### 4. 방송 꺼짐 표시

| 상황 | 기대 동작 |
|---|---|
| 칸의 채널이 방송 중이 아님 | 방송 화면을 비우고 "방송중이 아닙니다"를 띄운다. 닫기 버튼이 늘 보인다 |
| 그 채널이 방송을 시작함 | 1분 안에 알아채고 방송 화면을 채운다 |

[^1]: 브라우저는 확장 프로그램이 만든 화면에 로그인 정보를 저절로 실어 주지 않는다. 그래서 따로 실어 보낸다. 실어 보내는 정보는 플랫폼마다 다르다 — [치지직](../../External-Interfaces/Chzzk.md#13-로그인-판단과-인증-쿠키) · [SOOP](../../External-Interfaces/Soop.md#13-로그인-판단과-인증-쿠키)
[^2]: 플랫폼 방송 화면은 일정 폭 아래로 줄어들지 않아, 칸이 좁으면 잘리거나(SOOP) 칸 밖으로 삐져나가 스크롤 막대가 생긴다(치지직). 페이지 안을 고칠 수는 없으므로 넓게 그린 뒤 통째로 줄인다. 플랫폼별 증상은 [치지직](../../External-Interfaces/Chzzk.md#14-좁은-칸에서-생기는-스크롤-막대) · [SOOP](../../External-Interfaces/Soop.md#22-좁은-칸에서의-화면-깨짐) 참고.
