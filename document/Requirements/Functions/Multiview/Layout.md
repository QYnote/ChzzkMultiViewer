# 칸 배치

> **다루는 내용:** 칸을 나누는 규칙, 처음 배치, 배치를 바꾸고 기억하는 일
> **갱신 트리거:** 칸을 나누는 규칙이나 배치 조작 방법이 바뀔 때

## 본문

### 1. 칸을 나누는 규칙

배치는 **칸을 쪼개서** 만든다. 쪼갤 때 그은 선은 언제나 그 칸을 끝에서 끝까지 가로지른다.

```
┌──────────┬──────────┐   만들 수 있는 모양
│          │  채널 B  │   왼쪽은 세로 전체를 쓰고
│  채널 A  ├──────────┤   오른쪽만 위아래로 나뉘었다
│          │  채널 C  │
└──────────┴──────────┘

┌──────┬───┐
│  A   │   │   만들 수 없는 모양
├───┬──┤ B │   가로로도 세로로도
│ C │E │   │   끝까지 관통하는 선이 없다
│   ├──┴───┤
│   │  D   │
└───┴──────┘
```

- 칸 크기는 **비율로** 기억한다. 창 크기를 바꿔도 배치가 그대로다.
- 칸은 정해진 최소 크기보다 작아지지 않는다.

### 2. 처음 열었을 때의 배치

저장된 배치가 없으면 시청 목록의 채널 수에 맞춰 깐다.

| 채널 수 | 모양 |
|---|---|
| 1 | 화면 전체 |
| 2 | 좌우 반반 |
| 3 | 왼쪽에 위아래 둘, 오른쪽에 큰 칸 하나. 목록의 첫 채널이 큰 칸을 차지한다 |
| 4 | 2×2 |
| 5 이상 | 정사각형에 가까운 균등 격자 |

한 번 배치가 저장된 뒤로는 이 규칙과 목록 순서를 쓰지 않는다.

### 3. 배치 바꾸기

| 하고 싶은 것 | 어떻게 | 기대 동작 |
|---|---|---|
| 칸 크기 조절 | 칸 사이 경계를 끈다 | 경계 양쪽 두 칸의 크기만 바뀐다 |
| 자리 바꾸기 | 칸의 손잡이를 잡아 다른 칸 **가운데**에 놓는다 | 두 칸의 채널이 맞바뀐다. 칸 모양은 그대로다 |
| 쪼개서 넣기 | 손잡이를 잡아 다른 칸 **가장자리**에 놓는다 | 옮긴 칸이 빠진 자리는 옆 칸이 흡수하고, 놓은 칸이 그쪽으로 갈라져 들어간다 |
| 끌기 취소 | 놓기 전에 Esc | 아무것도 바뀌지 않는다 |

- 끄는 동안 **어디에 들어갈지 미리 보여 준다.** 가운데는 칸 전체가, 가장자리는 그쪽 절반이 물든다.
- 쪼갠 결과가 최소 크기보다 작아질 상황이면 가장자리는 받지 않고 자리 바꾸기만 받는다.
- 배치를 바꿔도 **방송 화면은 다시 읽지 않는다.** 보던 방송이 끊기지 않는다 — [품질 속성](../../Quality-Attributes.md#1-시청이-끊기지-않음)

**주의**
- ⚠️ 방송 화면 위에서 누른 마우스는 방송 페이지가 먼저 가져간다. 그래서 칸 아무 곳이나 잡아 끌 수는 없고 **손잡이를 잡아야** 한다.

### 4. 배치 기억

| 상황 | 기대 동작 |
|---|---|
| 배치를 바꿈 | 바로 저장한다. 다시 열어도 그대로다 |
| 시청 목록에서 빠진 채널이 있음 | 대시보드가 목록을 읽을 때 그 칸을 없애고 옆 칸이 자리를 흡수한다 |
| 시청 목록에 새 채널이 있음 | 가장 넓은 칸을 쪼개서 넣는다 |
| 저장된 배치가 깨져 있음 | 쓰지 않고 [처음 배치](#2-처음-열었을-때의-배치)로 새로 만든다 |
| 마지막 칸을 닫음 | 저장된 배치를 지운다 |
