# 여러 방송 동시 시청

> **다루는 내용:** 대시보드에서 여러 방송을 칸으로 나눠 보는 기능의 하위 요소 목록
> **갱신 트리거:** 하위 요소가 추가·제거될 때

채널마다 칸을 하나씩 준다. 모든 칸이 동등하며 주·보조 구분이 없다.

| [방송 칸 띄우기](Stream-Cell.md) | 로그인 상태로 띄우기, 끼워 넣기 제한 대응, 좁은 칸 축소, 방송 꺼짐 표시 |
| [칸 배치](Layout.md) | 칸을 나누는 규칙, 처음 배치, 크기 조절·자리 옮기기, 배치 기억 |
| [칸 조작](Cell-Controls.md) | 칸 조작 줄, 새로고침·닫기·영역 확대, 소리, 채널 표시 |
| [자동 처리](Automation.md) | 넓은 화면 전환, 채팅 접기, 광고 건너뛰기, 자동 동기화, 화면 안내 |
