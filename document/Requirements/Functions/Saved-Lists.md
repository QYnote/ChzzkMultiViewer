# 조합 보관·주고받기

> **다루는 내용:** 시청 목록 한 벌을 이름 붙여 보관하고 통째로 갈아타는 일, 글로 만들어 주고받는 일
> **갱신 트리거:** 저장된 목록이나 공유 글을 다루는 방법, 공유 글 형식이 바뀔 때

## 본문

### 1. 저장된 목록

여러 조합을 만들어 두고 오가기 위한 것이다. 시청 목록 자체는 따로 저장하지 않아도 늘 남아 있다.

| 하고 싶은 것 | 기대 동작 |
|---|---|
| 지금 시청 목록을 저장 | 이름을 받아 저장한다. 시청 목록이 비어 있으면 저장하지 않고 알린다 |
| 같은 이름으로 저장 | 덮어쓸지 묻고, 확인하면 덮어쓴다 |
| 저장된 목록으로 갈아타기 | 지금 시청 목록이 사라진다는 확인을 받은 뒤 **통째로 바꾼다.** 담긴 채널이 없으면 갈아타지 않고 알린다 |
| 남에게 보내기 | [공유 글](#2-공유-글)을 만들어 클립보드에 복사한다 |
| 담긴 채널 보기 | 펼쳐서 보여 준다. 보기만 한다 |
| 이름 바꾸기 | 이름을 세 번 연이어 누르면 고칠 수 있다. 같은 이름이 이미 있으면 바꾸지 않고 알린다 |
| 지우기 | 확인을 받고 지운다 |

- 갈아타도 열려 있는 대시보드는 그 자리에서 바뀌지 않는다 — [대시보드에 반영](Channel-Selection.md#4-대시보드에-반영)
- 저장하는 것은 **채널 목록뿐이다.** 화면 배치는 담지 않는다. 배치는 채널마다 자리가 기억되므로 담지 않아도 유지된다.
- 저장 당시의 닉네임이 그대로 남는다. 스트리머가 이름을 바꿔도 옛 이름이 보이지만, 방송은 채널 고유 ID로 띄우므로 시청에는 지장이 없다.

### 2. 공유 글

시청 목록 한 벌을 글로 만들어 남과 주고받는다.

```
치지직|채널고유ID|닉네임
SOOP|채널고유ID|닉네임
```

- **한 줄에 채널 하나뿐이다.** 표식도 목록 이름도 담지 않는다.
- 구분자는 세로줄이다.[^1]

| 받은 글을 붙여넣었을 때 | 기대 동작 |
|---|---|
| 모두 온전함 | 지금 시청 목록이 사라진다는 확인을 받은 뒤 **통째로 바꾼다** |
| 일부 줄만 깨짐 | 읽을 수 있는 것만 담고, 건너뛴 줄 수를 확인 창에 알린다 |
| 모르는 플랫폼 이름이 적힌 줄 | 그 줄만 건너뛴다 |
| 같은 채널이 두 번 적힘 | 한 번만 담는다 |
| 한 채널도 못 읽음 | 우리 글이 아니라고 보고 갈아타지 않는다 |
| 첫 줄에 표식과 목록 이름이 든 예전 글 | 첫 줄만 읽지 못한 줄로 세고 채널은 모두 담는다 |
| 갈아탄 뒤 저장하려 함 | 글에 이름이 없으므로 이름은 직접 적는다 |

- 붙여넣은 글은 저장되지 않는다. 남겨 두려면 이어서 지금 목록을 저장한다.
- 붙여넣기는 **입력창으로 받는다.**[^2]

**주의**
- ⚠️ 공유 글 형식은 배포되는 순간 **바꾸기 어려운 약속**이 된다. 남이 보낸 글을 읽어야 하므로, 형식을 바꾸면 예전에 오간 글을 읽지 못한다.

[^1]: 닉네임에 공백이 흔해서다. 공백으로 나누면 이름이 잘린다. 닉네임 안에 세로줄이 들어 있어도 읽을 수 있다. 채널 고유 ID에는 세로줄이 쓰이지 않는다는 플랫폼 규칙에 기댄다.
[^2]: 클립보드를 프로그램이 직접 읽으려면 권한이 하나 더 필요하다. 입력창으로 받으면 권한이 필요 없다 — [제약](../Constraints.md#2-설치-때-받는-권한)
