# 채널 모아 두기

> **다루는 내용:** 채널을 하나하나 폴더로 모아 두는 즐겨찾기
> **갱신 트리거:** 즐겨찾기를 다루는 방법이 바뀔 때

## 본문

즐겨찾기는 시청 목록과 **완전히 별개**다. 한쪽에서 지워도 다른 쪽은 그대로다. 폴더로 나눌 수 있고 깊이 제한이 없다.[^1]

| 하고 싶은 것 | 기대 동작 |
|---|---|
| 맨 위 폴더 만들기 | 맨 위에 "새 폴더"를 만든다 |
| 하위 폴더 만들기 | 그 폴더 안에 "새 폴더"를 만든다 |
| 폴더 이름 바꾸기 | 이름을 세 번 연이어 누르면 고칠 수 있다. Enter나 다른 곳을 누르면 저장, Esc로 취소 |
| 접기·펼치기 | 접은 상태를 기억한다 |
| 폴더 지우기 | 안에 무언가 있으면 확인을 받고, 확인하면 안의 것까지 함께 지운다 |
| 채널 순서 바꾸기 | 같은 폴더 안에서 끌어다 놓는다 |
| 채널을 다른 폴더로 | 그 폴더 머리 위에 놓는다 |
| 폴더 순서 바꾸기 | 같은 단계의 폴더끼리만 끌어다 놓을 수 있다 |
| 맨 위로 꺼내기 | 맨 위 폴더 만들기 버튼 위에 놓는다 |
| 시청 목록에 넣기 | 복사한다. 즐겨찾기 쪽은 그대로 남는다. 이미 시청 목록에 있으면 넣지 않고 알린다 |
| 다른 곳에서 즐겨찾기에 넣기 | 시청 목록·팔로잉 목록에서 넣으면 **맨 위 폴더**에 들어간다 |
| 같은 채널을 또 넣기 | 트리 전체에서 이미 있으면 넣지 않는다 |

- 채널마다 플랫폼 아이콘과 방송 중 여부를 표시한다.

[^1]: 저장된 목록과도 다르다. 즐겨찾기는 채널을 **모아 두는** 곳이고, 저장된 목록은 시청 목록 **한 벌을 통째로** 보관한다 — [조합 보관](Saved-Lists.md)
