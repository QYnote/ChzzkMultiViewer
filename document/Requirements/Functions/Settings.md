# 설정

> **다루는 내용:** 사용자가 바꿀 수 있는 값과 반영 시점
> **갱신 트리거:** 설정 항목이나 고를 수 있는 값, 기본값이 바뀔 때

## 본문

| 설정 | 고를 수 있는 것 | 처음 설치했을 때 |
|---|---|---|
| 방송 칸 채널 표시 | 항상 표시 / 마우스 올릴 때 **×** 프로필 사진 / 채널 이름 = 4가지 | 마우스 올릴 때 · 채널 이름 |
| 자동 동기화 | 켜기 / 끄기 | 켜짐 |
| 허용 지연 시간 | 초 단위 정수 | 10초 |

| 상황 | 기대 동작 |
|---|---|
| 설정을 바꿈 | 바꾸는 즉시 저장한다 |
| 대시보드가 열려 있음 | **새로고침 없이** 바로 적용한다 |
| 허용 지연 시간에 숫자가 아닌 값 | 10초로 둔다 |
| 예전 버전에서 쓰던 표시 방식 값이 남아 있음 | 지금 체계의 값으로 바꿔 읽는다 — [데이터](../Data.md#4-시스템-설정) |

- 설정 화면에는 현재 버전과 GitHub · X(트위터) 링크도 있다.
- 각 설정이 실제로 하는 일은 [칸의 채널 표시](Multiview/Cell-Controls.md#3-칸의-채널-표시) · [자동 동기화](Multiview/Automation.md#3-자동-동기화) 참고.
