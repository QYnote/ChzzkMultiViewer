# 사용자 화면

> **다루는 내용:** 팝업과 대시보드에 무엇이 어디에 놓이는지, 알림을 어떻게 띄우는지
> **갱신 트리거:** 화면 구성이나 알림 방식이 바뀔 때

## 본문

각 조작이 무엇을 하는지는 [기능](../Functions/README.md)에 있다. 이 문서는 **어디에 놓이는지**만 다룬다.

### 1. 팝업

탭이 둘이다.

```
시청목록 ─ 멀티뷰 대시보드 열기 (좌우 위 전체 폭)
          ├ 왼쪽  멀티뷰 표시 목록 + 현재 목록 저장
          └ 오른쪽 ┬ 채널 추가 (처음 보이는 화면) ─ 치지직 / SOOP로 한 번 더 나뉨
                   ├ 즐겨찾기
                   └ 저장 목록
기타설정                          방송 칸 채널 표시 · 자동 동기화 · 버전 · 링크
```

| 자리 | 담는 기능 |
|---|---|
| 왼쪽 칸 | [시청 목록 다루기](../Functions/Channel-Selection.md#3-시청-목록-다루기), 지금 목록 저장 |
| 오른쪽 · 채널 추가 | [직접 추가](../Functions/Channel-Selection.md#1-직접-추가) → [팔로잉에서 추가](../Functions/Channel-Selection.md#2-팔로잉에서-추가) → [받은 글 붙여넣기](../Functions/Saved-Lists.md#2-공유-글) 순 |
| 오른쪽 · 즐겨찾기 | [채널 모아 두기](../Functions/Favorites.md) |
| 오른쪽 · 저장 목록 | [저장된 목록](../Functions/Saved-Lists.md#1-저장된-목록) |
| 기타설정 탭 | [설정](../Functions/Settings.md) |

- 왼쪽을 고정한 까닭은 오른쪽에서 무엇을 하든 **결과가 왼쪽에 쌓이기 때문이다.**
- 오른쪽 칸은 팝업 폭의 절반이라 채널 추가 화면이 칸보다 길다. **칸 안에서 세로로 스크롤**하며, 팝업 전체 높이는 늘어나지 않는다.
- 받은 글 붙여넣기를 맨 아래에 둔 까닭은 채널 하나를 더하는 위의 둘과 달리 **목록을 통째로 갈아치우기** 때문이다.

### 2. 대시보드

채널마다 칸 하나. 칸 안에는 방송 화면이 있고 그 위에 조작 줄이 겹친다.

```
┌────────────────────────────────────────┐
│  채널 표시        딜레이 · 새로고침 ·    │
│                   손잡이 · 메뉴 · 닫기   │
│                                        │
│              방송 화면                  │
│                                        │
│   ← 아래쪽은 방송 페이지의 조작 막대 자리 → │
└────────────────────────────────────────┘
```

- 조작 줄은 마우스를 올렸을 때만 보인다. 방송이 꺼진 칸은 닫기 버튼이 늘 보인다.
- 아래쪽은 방송 페이지가 쓰도록 비워 둔다 — [칸 조작](../Functions/Multiview/Cell-Controls.md#1-칸-조작-줄)
- 화면 위쪽에 자동 동기화가 켜져 있는지와 그 기준 초를 보여 준다.

### 3. 알림

| 화면 | 방식 |
|---|---|
| 팝업 | 추가·삭제·저장 결과를 화면 아래쪽에 짧게 띄운다. 약 2.5초 뒤 사라지고, 새 알림이 뜨면 이전 것은 바로 바뀐다. 실패는 붉은색 |
| 팝업 | 되돌릴 수 없는 일(목록 덮어쓰기·지우기)은 확인 창으로 묻는다 |
| 대시보드 | 칸 안에 상태 안내를 겹쳐 띄운다 — [화면에 나타나는 안내](../Functions/Multiview/Automation.md#4-화면에-나타나는-안내) |
