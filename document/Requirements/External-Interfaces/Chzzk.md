# 치지직 (Chzzk)

> **다루는 내용:** 치지직이 정한 값과 동작 중 이 프로그램이 기대는 것
> **갱신 트리거:** 치지직이 주소·쿠키·응답·화면 구조를 바꿔 대응이 필요할 때

## 본문

**치지직이 정한 것**이라 우리가 바꿀 수 없다. 치지직 쪽이 바뀌면 이 문서와 대응한 곳을 함께 고친다. 이 문서는 치지직이 **어떻게 동작하는지**만 적고, 우리가 무엇을 하는지는 링크로 가리킨다.

### 1. 치지직이 정한 값

#### 1.1 채널 ID

- 정확히 32자리 영문·숫자
- 방송 주소에서 확인한다

#### 1.2 주소 형식

| 용도 | 주소 |
|---|---|
| 방송 화면 | `https://chzzk.naver.com/live/{채널ID}` |
| 팔로잉 목록 | `https://api.chzzk.naver.com/service/v1/channels/followings` |
| 생방송 상태·프로필 사진 | `https://api.chzzk.naver.com/service/v1/channels/{채널ID}` |

#### 1.3 로그인 판단과 인증 쿠키

로그인 정보는 아래 쿠키에 있다. 이 프로그램은 **쿠키가 있는지로만** 로그인을 판단하고, 실제 요청을 보내 확인하지 않는다.

| 쿠키 이름 | 뜻 | 로그인 판단에 씀 | 방송 화면·조회에 실어 보냄 |
|---|---|---|---|
| `NID_AUT` | 네이버 로그인 인증 | ✅ 둘 다 있어야 로그인으로 본다 | ✅ |
| `NID_SES` | 네이버 세션 | ✅ | ✅ |
| `nid_inf` | 네이버 부가 정보 | — | ✅ |

**주의**
- ⚠️ 세 쿠키는 치지직 전용이 아니라 **네이버 전체의 로그인 쿠키**다. 그래서 치지직에 한 번도 들어간 적이 없어도 네이버에만 로그인돼 있으면 로그인된 것으로 판단된다.
- ⚠️ 쿠키 이름이 바뀌거나 세션이 만료되면 팔로잉 목록을 불러오지 못한다 — [팔로잉에서 추가](../Functions/Channel-Selection.md#2-팔로잉에서-추가)

#### 1.4 좁은 칸에서 생기는 스크롤 막대

치지직 방송 페이지는 **일정 폭 아래로 줄어들지 않는다.** 그보다 좁은 곳에 넣으면 페이지가 밖으로 삐져나가 스크롤 막대가 생긴다.

| 항목 | 값 |
|---|---|
| 잰 최소 폭 | **950px** — 칸을 303px로도 934px로도 줄여 봤지만 페이지 폭이 950px에서 멈췄다 |
| 확인한 날 | 2026-10-07 |

- 넓은 화면이 걸린 상태에서도 생긴다. **넓은 화면과는 무관한 제약**이라 넓은 화면을 다시 걸거나 껐다 켜도 없어지지 않는다.
- 가로 막대가 생기면 그 두께만큼 세로가 모자라 **세로 막대까지 딸려 나온다.**
- 대응: [좁은 칸 축소](../Functions/Multiview/Stream-Cell.md#3-좁은-칸-축소)

#### 1.5 다른 페이지 안에 끼워 넣기 제한

치지직 페이지는 응답에 **"이 페이지를 어느 주소 안에 끼워 넣을 수 있는가"를 정하는 보안 규칙**을 실어 보낸다. 허용된 곳은 치지직 자신과 네이버 주소뿐이다.

| 항목 | 값 |
|---|---|
| 규칙이 실리는 곳 | 응답 헤더 `Content-Security-Policy` |
| 규칙 내용 | `frame-ancestors 'self' https://naver.com https://*.naver.com` |
| 걸리는 범위 | 치지직 페이지 전체 — 방송 주소와 첫 화면 모두 |
| 확인한 날 | 2026-10-07 |

- 대시보드는 네이버 주소가 아니므로 그대로 두면 칸에 "chzzk.naver.com이(가) 차단되었습니다"가 뜬다. 대응: [끼워 넣기 제한 대응](../Functions/Multiview/Stream-Cell.md#2-끼워-넣기-제한-대응)

**주의**
- ⚠️ 이 규칙이 생기기 전에는 아무 처리 없이 칸에 들어갔다. 우리 쪽은 바뀐 것이 없었으므로 **치지직 쪽 변경**이다.
- ⚠️ 같은 목적의 옛 방식 헤더(`X-Frame-Options`)는 **실리지 않는다.** 외부 자료에는 그쪽으로 소개된 경우가 있으나 확인일의 실제 응답에는 없었다. 증상이 다시 생기면 추측하지 말고 실제 응답 헤더부터 본다.
- ⚠️ 확인일 기준으로 이 헤더에는 **끼워 넣기 제한 하나만** 실려 있다. 같은 헤더에 다른 보안 규칙이 함께 실리기 시작하거나 제한이 다른 헤더로 옮겨 가면 대응을 다시 확인해야 한다.

### 2. 화면 요소

방송 페이지 안에서 찾고 누르는 부분이다. 자동 처리가 먹지 않는 증상이 생기면 여기부터 확인한다.

| 대상 | 판별·조작 방법 |
|---|---|
| 넓은 화면 전환 버튼 | 이름표가 "넓은 화면"인 버튼. 누를 때마다 켜고 끈다 |
| 넓은 화면 여부 | 재생기 영역에 확대 상태를 뜻하는 표시가 붙었는지 본다 |
| 채팅 접기 버튼 | 이름표가 "채팅 접기"인 버튼 |
| 광고 재생 중 여부 | 건너뛰기 안내 요소가 있는지 본다 |
| 광고 건너뛰기 버튼 | 건너뛰기 버튼이 숨김 상태가 아니면 누를 수 있다 |
