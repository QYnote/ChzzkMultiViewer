# SOOP

> **다루는 내용:** SOOP이 정한 값과 동작 중 이 프로그램이 기대는 것
> **갱신 트리거:** SOOP이 주소·쿠키·응답·화면 구조를 바꿔 대응이 필요할 때

## 본문

**SOOP이 정한 것**이라 우리가 바꿀 수 없다. SOOP 쪽이 바뀌면 이 문서와 대응한 곳을 함께 고친다. 이 문서는 SOOP이 **어떻게 동작하는지**만 적고, 우리가 무엇을 하는지는 링크로 가리킨다.

### 1. SOOP이 정한 값

#### 1.1 채널 ID

- 영문·숫자 조합, 자릿수 규칙 없음
- 방송 주소에서 확인한다

#### 1.2 주소 형식

| 용도 | 주소 |
|---|---|
| 방송 화면 | `https://play.sooplive.com/{채널ID}` |
| 팔로잉 목록 | `https://myapi.sooplive.com/api/favorite` |
| 생방송 상태 | `https://live.sooplive.com/afreeca/player_live_api.php` |
| 프로필 사진 | `https://stimg.sooplive.com/LOGO/{채널ID 앞 2자}/{채널ID}/m/{채널ID}.webp` |

- 생방송 상태는 다른 조회와 달리 주소가 아니라 **본문에 값을 실어** 요청한다.
- 채팅 주소는 쓰지 않는다.

#### 1.3 로그인 판단과 인증 쿠키

- 로그인 여부는 **팔로잉 목록을 실제로 요청해** 정상 목록이 돌아오는지로 판단한다. 치지직처럼 쿠키 존재만 보지 않으므로 오탐이 없다.
- 실어 보낼 쿠키는 이름을 정하지 않고 **두 도메인의 것을 전부** 모은다.

| 도메인 | 우선순위 |
|---|---|
| `sooplive.com` | 이름이 겹치면 이쪽이 이긴다 |
| `sooplive.co.kr` | |

#### 1.4 다른 페이지 안에 끼워 넣기 제한

2026-10-07 확인 기준으로 SOOP 방송 페이지는 **끼워 넣을 수 있는 곳을 제한하는 규칙을 싣지 않는다.** 따로 처리하지 않아도 칸에 들어간다.

- 같은 날 치지직은 이 제한을 새로 걸었다 — [치지직](Chzzk.md#15-다른-페이지-안에-끼워-넣기-제한). SOOP 칸에 "차단되었습니다"가 뜨면 같은 원인부터 의심하고 실제 응답 헤더를 확인한다.

### 2. 끼워 넣을 때 드러나는 동작

#### 2.1 고화질 재생기

SOOP 고화질 재생기는 **로컬 앱이 깔려 있는지 확인하려고 내 컴퓨터 주소(`127.0.0.1`·`localhost`)로 요청을 보낸다.** 그대로 두면 브라우저가 권한 요청 창을 띄운다. 이 요청이 실패하면 재생기는 로컬 앱이 없다고 보고 일반 재생으로 넘어간다.

- 이 요청은 방송 페이지 자체의 코드가 보내므로, 막으려면 **페이지와 같은 실행 영역**에서 손을 써야 한다.
- 대응: [SOOP 전용 처리](../Functions/Multiview/Automation.md#5-soop-전용-처리)

#### 2.2 좁은 칸에서의 화면 깨짐

SOOP 방송 페이지는 **폭이 좁아지면 화면이 잘리고 왼쪽에 빈 여백이 생긴다.** 페이지가 정한 최소 너비 아래로는 제대로 그려지지 않는다.

- 대응: [좁은 칸 축소](../Functions/Multiview/Stream-Cell.md#3-좁은-칸-축소)

### 3. 화면 요소

방송 페이지 안에서 찾고 누르는 부분이다. 자동 처리가 먹지 않는 증상이 생기면 여기부터 확인한다.

| 대상 | 판별·조작 방법 |
|---|---|
| 넓은 화면 전환 버튼 | 화면 모드 전환 버튼 |
| 넓은 화면 여부 | 화면 전체에 확대 상태를 뜻하는 표시가 붙었는지 본다 |
| 고화질 연결 안내 창 | 로컬 앱 미설치를 뜻하는 버튼이 나타나면 눌러 닫는다 |
| 채팅 영역 | 채팅 영역이 보이면 닫기 버튼으로 접는다 |
| 광고 재생 중 여부 | 건너뛰기 버튼 요소가 있는지 본다 |
| 광고 건너뛰기 버튼 | 버튼이 활성화되고 보이는 상태면 누를 수 있다 |

**주의**
- ⚠️ 채팅 영역 닫기 버튼은 누를 때 페이지 보안 정책 위반 오류가 날 수 있다. 버튼에 걸린 연결 주소 때문이다.
