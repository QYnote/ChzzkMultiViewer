# 치지직 (Chzzk)

> **다루는 내용:** 치지직 플랫폼이 정한 값과 규칙 (주소 형식, 인증 쿠키, 화면 요소)
> **갱신 트리거:** 치지직이 주소·쿠키·화면 구조를 바꿔 대응이 필요할 때

## 본문

### 1. 치지직이 정한 값

**치지직이 정한 것**이라 우리가 바꿀 수 없다. 치지직 쪽이 바뀌면 이 문서와 코드를 함께 고쳐야 한다.

#### 1.1 채널 ID

- 정확히 32자리 영문/숫자
- 방송 주소에서 확인한다

#### 1.2 주소 형식

| 용도 | 주소 |
|---|---|
| 방송 화면 | `https://chzzk.naver.com/live/{채널ID}` |
| 팔로잉 목록 | `https://api.chzzk.naver.com/service/v1/channels/followings` |
| 생방송 상태·프로필 사진 | `https://api.chzzk.naver.com/service/v1/channels/{채널ID}` |

#### 1.3 로그인 판단과 인증 쿠키

로그인 여부를 **쿠키가 있는지로만** 판단한다. 실제 요청을 보내 확인하지 않는다.

| 쿠키 이름 | |
|---|---|
| `NID_AUT` | 네이버 로그인 인증 |
| `NID_SES` | 네이버 세션 |
| `nid_inf` | 네이버 부가 정보 |

**주의**
- ⚠️ 세 쿠키는 치지직 전용이 아니라 **네이버 전체에서 쓰이는 로그인 쿠키**다. 그래서 치지직에 한 번도 들어간 적이 없어도 네이버에만 로그인돼 있으면 "치지직 로그인됨"으로 판단된다.
- ⚠️ 쿠키 이름이 바뀌거나 세션이 만료되면 팔로잉 목록을 불러오지 못한다. 이때는 실패 안내와 함께 치지직 홈으로 가는 링크를 보여준다.

#### 1.4 좁은 칸에서 생기는 스크롤 막대

치지직 방송 페이지는 **일정 폭 아래로 줄어들지 않는다.** 칸이 그보다 좁으면 페이지가 칸 밖으로 삐져나가 스크롤 막대가 생긴다. 페이지 안을 고칠 수는 없다.

그래서 칸이 좁을 때는 **페이지를 그 최소 폭으로 그린 뒤 칸 크기에 맞춰 줄여서 끼운다.** [SOOP](Soop.md#22-좁은-칸에서의-화면-깨짐)에 쓰던 방법과 같고, 값만 플랫폼마다 다르다.

**주의**
- ⚠️ **넓은 화면과는 무관한 제약이다.** 넓은 화면이 걸린 상태에서도 생긴다. 넓은 화면을 다시 걸거나 껐다 켜는 방법으로는 없어지지 않는다.
- ⚠️ 가로 막대가 생기면 그 두께만큼 세로가 모자라 **세로 막대까지 딸려 나온다.** 가로를 잡으면 둘 다 사라지므로 세로를 따로 다루지 않는다.
- ⚠️ 기준 너비는 관측으로 정한 값이다. 칸을 여러 크기로 줄여 봐도 페이지 폭이 더 내려가지 않는 지점을 최소 폭으로 삼았다. 치지직이 화면 구조를 바꾸면 다시 재야 한다.

### 화면 요소

방송 페이지 안에서 조작하는 부분이다. 조작이 먹지 않는 증상이 생기면 여기부터 확인한다.

| 대상 | 판별·조작 방법 |
|---|---|
| 넓은 화면 전환 버튼 | 이름표가 "넓은 화면"인 버튼을 누른다 |
| 넓은 화면 여부 | 재생기 영역에 확대 상태를 뜻하는 표시가 붙었는지 본다 |
| 채팅 접기 버튼 | 이름표가 "채팅 접기"인 버튼을 누른다 |
| 광고 재생 중 여부 | 건너뛰기 안내 요소가 있는지 본다 |
| 광고 건너뛰기 버튼 | 건너뛰기 버튼이 숨김 상태가 아니면 누른다 |
