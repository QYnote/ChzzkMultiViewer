# 팝업 화면

> **다루는 내용:** 팝업에서 사용자가 할 수 있는 조작과 그 결과
> **갱신 트리거:** 팝업의 조작 방법이나 화면 구성이 바뀔 때

## 본문

### 화면 구성

시청목록 탭은 **좌우 두 칸으로 나뉜 한 화면**이다. 왼쪽은 대시보드에 뜰 목록으로 고정이고, 오른쪽만 세 화면을 갈아끼운다.

```
시청목록 ─ 멀티뷰 대시보드 열기 (좌우 위 전체 폭)
          ├ 왼쪽  대시보드 표시 목록 + 현재 목록 저장
          └ 오른쪽 ┬ 채널 추가 (처음 보이는 화면) ─ 치지직 / SOOP로 한 번 더 나뉨
                   ├ 즐겨찾기 채널
                   └ 저장한 표시 목록
기타설정                          표시 방식 · 자동 동기화
```

- 왼쪽을 고정한 까닭은 오른쪽에서 무엇을 하든 **결과가 왼쪽에 쌓이기 때문이다.** 채널을 더하든 목록을 통째로 갈아타든 바뀌는 곳이 늘 보인다.
- 오른쪽 칸은 팝업 폭의 절반뿐이라 채널 추가 화면이 칸보다 길다. **칸 안에서 세로로 스크롤**하며, 팝업 전체 높이는 늘어나지 않는다.

### 1. 시청 목록 탭

볼 채널을 고르고 정리하는 탭이다.

#### 1.1 시청 목록 다루기

왼쪽 칸에서 한다. **여기 담긴 채널이 대시보드에 뜬다.** 어느 채널이 어디에 놓일지는 대시보드가 채널마다 따로 기억하므로, 이 목록에는 순서라는 개념이 없다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 즐겨찾기에 넣기 | 항목의 별 버튼 |
| 목록에서 빼기 | 항목의 삭제 버튼 |
| 지금 목록을 이름 붙여 저장 | 목록 제목 옆 `현재 목록 저장` → 이름 입력 |
| 대시보드 열기 | `멀티뷰 대시보드 열기` 버튼 |

- 각 항목은 닉네임과 플랫폼 아이콘으로 표시된다.
- 별 버튼은 **넣기만 된다.** 이미 즐겨찾기에 있으면 색이 채워진 채 잠기고, 빼는 것은 즐겨찾기 목록에서 한다.
- 저장 조작을 이 칸에 둔 까닭은 **저장 대상이 이 목록이기 때문이다.** 저장된 결과를 보려면 오른쪽을 `저장한 표시 목록`으로 바꾼다.
- 대시보드가 **이미 열려 있으면 새 탭을 만들지 않는다.** 기존 탭으로 이동하며 바뀐 목록을 바로 반영한다.
  - 담긴 채널이 그대로면 대시보드는 아무것도 다시 읽지 않는다. 보고 있던 방송이 끊기지 않는다.

#### 1.2 채널 추가하기

오른쪽 칸의 **처음 보이는 화면**이다. 목록을 채우는 세 가지 방법이 한데 모여 있다. 치지직·SOOP 중 어느 플랫폼인지 먼저 고른 뒤 쓴다.

**직접 입력하기**

`채널 고유 ID`와 `스트리머 이름`을 각각 입력하고 `시청 목록에 추가`를 누른다.

- 채널 ID는 방송 주소에서 확인한다. 형식은 플랫폼마다 달라 [치지직](Chzzk.md) · [SOOP](Soop.md) 참고.
- 특수문자는 입력이 제한되고 형식이 맞는지 검사한다.
- 이미 시청 목록에 있는 채널은 추가되지 않는다.

**팔로잉 목록에서 고르기**

직접 입력 바로 아래에 있다. `내 팔로잉 목록 불러오기` 버튼을 누르며, 로그인이 안 돼 있으면 버튼 대신 안내 문구가 뜬다.

- 불러온 목록은 **LIVE 방송이 위로** 정렬되고 LIVE/OFF 배지가 붙는다.
- 항목마다 즐겨찾기 추가·시청 목록 추가 버튼이 있다. 이미 즐겨찾기에 있으면 노란 버튼, 없으면 회색 버튼이고, 이미 시청 목록에 있으면 "추가됨"으로 눌리지 않는다.
- 목록을 못 불러오면(로그인 만료 등) 실패 안내와 함께 해당 플랫폼 홈으로 가는 링크가 나온다.

**받은 글로 목록 불러오기**

맨 아래에 있다. 남이 보낸 공유 글을 입력창에 붙여넣고 아래 버튼을 누른다. 글 형식과 갈아타기 동작은 [1.4](#14-저장한-표시-목록-다루기)에 정리돼 있다.

- 입력창이 **늘 보인다.** 여는 버튼을 따로 두지 않는다.
- 이것만 플랫폼 선택과 무관하다. 어느 플랫폼의 채널인지는 글 안에 적혀 있다. 채널 하나를 더하는 위의 둘과 달리 **목록을 통째로 갈아치우므로** 맨 아래에 둔다.

**주의**
- ⚠️ 치지직은 **네이버에만 로그인돼 있어도 "로그인됨"으로 보인다.** SOOP은 이런 오인식이 없다. 까닭은 [치지직](Chzzk.md) 참고.

#### 1.3 즐겨찾기 채널 다루기

시청 목록과 **완전히 별개인 저장 공간**이다. 한쪽에서 지워도 다른 쪽은 그대로다. 채널을 하나하나 모아 두는 곳으로, 폴더로 분류할 수 있고 깊이 제한이 없다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 최상위 폴더 만들기 | `+ 폴더 추가` 버튼 |
| 하위 폴더 만들기 | 각 폴더의 `+ 폴더` 버튼 |
| 폴더 이름 바꾸기 | 이름을 3번 연속 클릭 → Enter 또는 다른 곳 클릭으로 저장, Esc로 취소 |
| 접기 / 펼치기 | 폴더 옆 화살표(▶/▼) |
| 폴더 지우기 | 하위 항목이 있으면 확인 창이 뜨고, 확인하면 하위까지 함께 삭제 |
| 항목 순서 바꾸기 | 같은 폴더 안에서 드래그 |
| 항목을 다른 폴더로 | 그 폴더 헤더 위에 드롭 |
| 폴더 순서 바꾸기 | 폴더 헤더를 드래그 (같은 레벨끼리만) |
| 최상위로 꺼내기 | `+ 폴더 추가` 버튼 위에 드롭 |
| 시청 목록에 넣기 | 복사 버튼. 원본은 남고, 이미 있는 채널은 중복 추가되지 않는다 |

- 항목마다 플랫폼 아이콘과 LIVE/OFF 배지가 표시된다.
- 팔로잉 목록이나 시청 목록에서 즐겨찾기에 추가하면 **최상위**에 들어간다.

#### 1.4 저장한 표시 목록 다루기

시청 목록 **한 벌 전체**를 이름 붙여 보관해 두고, 나중에 통째로 갈아타는 곳이다. 오른쪽 칸의 세 번째 화면이다.

즐겨찾기와는 담는 것이 다르다. 즐겨찾기는 채널 하나하나를 폴더로 **모아 두는** 곳이고, 여기는 목록 **한 벌을 통째로** 보관한다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 지금 시청 목록을 저장 | 왼쪽 칸의 `현재 목록 저장` → 이름 입력. 같은 이름이 있으면 덮어쓸지 묻는다 |
| 남이 보낸 글로 갈아타기 | `채널 추가` 화면의 붙여넣기 입력창 ([1.2](#12-채널-추가하기)) |
| 저장된 목록으로 갈아타기 | 항목의 불러오기 버튼 |
| 남에게 보내기 | 항목의 공유 버튼. 글이 클립보드에 복사된다 |
| 담긴 채널 확인 | 항목의 화살표로 펼친다 (보기 전용) |
| 이름 바꾸기 | 이름을 3번 연속 클릭 |
| 삭제 | 항목의 삭제 버튼 |

- **불러오면 지금 시청 목록은 사라진다.** 확인을 한 번 받는다.
- 대시보드가 열려 있으면 **손대지 않아도 그 조합으로 바뀐다.** 다만 담긴 채널이 지금과 똑같으면 다시 읽지 않아 보던 방송이 끊기지 않는다.
- 붙여넣기로 불러온 것은 **저장되지 않는다.** 남겨 두려면 왼쪽 칸의 `현재 목록 저장`을 이어서 누른다. 글에 이름이 담기지 않으므로 이름은 직접 적는다.
- 저장하는 것은 **채널 목록뿐이다.** 화면 배치는 담지 않는다. 배치는 채널마다 자기 자리를 따로 기억하므로 담지 않아도 유지된다.
- 저장 당시의 닉네임이 그대로 남는다. 스트리머가 이름을 바꿔도 옛 이름이 보이지만, 방송은 채널 고유 ID로 띄우므로 시청에는 지장이 없다.

**공유 글 형식**

```
치지직|채널고유ID|닉네임
SOOP|채널고유ID|닉네임
```

- **한 줄에 채널 하나뿐이다.** 표식도 목록 이름도 담지 않는다.
- 구분자를 세로줄로 둔 까닭은 **닉네임에 공백이 흔해서다.** 공백으로 나누면 이름이 잘린다. 닉네임 안에 세로줄이 들어 있어도 읽을 수 있다. 채널 고유 ID에는 세로줄이 쓰이지 않는다는 플랫폼 규칙에 기댄다.
- 우리 글인지는 **채널 줄이 한 개라도 읽히는지**로 판단한다. 표식이 없으므로 이것이 유일한 근거다.

| 글이 온전치 않을 때 | 어떻게 |
|---|---|
| 일부 줄만 깨짐 | 읽을 수 있는 것만 담고, 건너뛴 줄 수를 알린다 |
| 모르는 플랫폼 이름 | 그 줄만 건너뛴다 (지원 플랫폼이 늘어날 때를 위해) |
| 한 채널도 못 읽음 | 우리 글이 아니라고 보고, 갈아타지 않고 알린다 |

**주의**
- ⚠️ 공유 글 형식은 배포되는 순간 **바꾸기 어려운 약속**이 된다. 남이 보낸 글을 우리가 읽어야 하므로, 형식을 바꾸면 예전에 오간 글을 읽지 못한다.
- ⚠️ 표식과 목록 이름을 담던 첫 줄은 **없앴다.** 그 줄이 든 예전 글을 받으면 첫 줄만 읽지 못한 줄로 세고 채널은 모두 들여온다. 갈아타는 데는 지장이 없다.
- ⚠️ 붙여넣기를 **입력창으로 받는 이유**가 있다. 클립보드를 프로그램이 직접 읽으려면 권한이 하나 더 필요한데, 입력창으로 받으면 권한 없이 된다.

### 2. 기타설정 탭

동작 방식을 바꾸는 값과 프로그램 정보가 있는 탭이다.

#### 2.1 설정 바꾸기

| 설정 | 고를 수 있는 것 | 처음 설치했을 때 |
|---|---|---|
| 방송 칸 채널 표시 | 항상 표시 / 마우스 올릴 때 **×** 프로필 사진 / 채널 이름 = 4가지 | 마우스 올릴 때 (채널 이름) |
| 자동 동기화 | 켜기 / 끄기 | 켜짐 |
| 허용 지연 시간 | 초 단위로 입력 | 10초 |

- 설정은 바꾸는 즉시 저장되고, 대시보드가 열려 있어도 **새로고침 없이** 바로 적용된다.
- 현재 버전 정보와 GitHub · X(Twitter) 링크도 이 탭에 있다.

### 공통

- 추가·삭제·저장 결과는 화면 아래쪽에 알림으로 뜬다. 약 2.5초 뒤 사라지고, 새 알림이 뜨면 이전 알림은 즉시 교체된다.
