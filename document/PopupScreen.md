# 팝업 화면

> **다루는 내용:** 팝업에서 사용자가 할 수 있는 조작과 그 결과
> **갱신 트리거:** 팝업의 조작 방법이나 화면 구성이 바뀔 때

## 본문

### 화면 구성

탭이 2단이다.

```
시청목록 ─┬─ 대시보드 표시 목록   멀티뷰 목록(좌) + 즐겨찾기(우)
          └─ 스트리머 추가        치지직 / SOOP 탭으로 한 번 더 나뉨
기타설정                          표시 방식 · 배치 · 자동 동기화
```

### 시청 목록 다루기

`시청목록 › 대시보드 표시 목록`에서 한다. 목록의 맨 위 `📌 메인 화면` 박스에 있는 스트리머가 대시보드의 메인이 되고, 그 아래가 서브 채널이다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 서브 순서 바꾸기 | 항목을 드래그하거나 위/아래 버튼. 맨 위 항목은 더 위로 못 간다 |
| 메인 바꾸기 | 서브를 `📌 메인 화면` 박스로 드래그, 또는 항목 메뉴(⋯) → `▶ 메인으로 지정` |
| 즐겨찾기에 넣기 | 항목 메뉴(⋯) → 즐겨찾기 추가. 이미 있으면 메뉴에 안 뜬다 |
| 목록에서 빼기 | 항목의 삭제 버튼 |
| 대시보드 열기 | `멀티뷰 대시보드 열기` 버튼 |

- 각 항목은 닉네임과 플랫폼 아이콘으로 표시된다.
- 대시보드가 **이미 열려 있으면 새 탭을 만들지 않는다.** 기존 탭으로 이동하며 바뀐 목록을 바로 반영한다.

### 즐겨찾기 다루기

시청 목록과 **완전히 별개인 저장 공간**이다. 한쪽에서 지워도 다른 쪽은 그대로다. 폴더로 분류할 수 있고 깊이 제한이 없다.

| 하고 싶은 것 | 어떻게 |
|---|---|
| 최상위 폴더 만들기 | `+ 폴더 추가` 버튼 |
| 하위 폴더 만들기 | 각 폴더의 `+ 폴더` 버튼 |
| 폴더 이름 바꾸기 | 이름을 3번 연속 클릭 → Enter 또는 다른 곳 클릭으로 저장, Esc로 취소 |
| 접기 / 펼치기 | 폴더 옆 화살표(▶/▼) |
| 폴더 지우기 | 하위 항목이 있으면 확인 창이 뜨고, 확인하면 하위까지 함께 삭제 |
| 항목 순서 바꾸기 | 같은 폴더 안에서 드래그 |
| 항목을 다른 폴더로 | 그 폴더 헤더 위에 드롭 |
| 폴더 순서 바꾸기 | 폴더 헤더를 드래그 (같은 레벨끼리만) |
| 최상위로 꺼내기 | `+ 폴더 추가` 버튼 위에 드롭 |
| 시청 목록에 넣기 | 복사 버튼. 원본은 남고, 이미 있는 채널은 중복 추가되지 않는다 |

- 항목마다 플랫폼 아이콘과 LIVE/OFF 배지가 표시된다.
- 팔로잉 목록이나 시청 목록에서 즐겨찾기에 추가하면 **최상위**에 들어간다.

### 스트리머 추가하기

`시청목록 › 스트리머 추가`에서 치지직·SOOP 탭을 고른 뒤 두 가지 방법 중 하나를 쓴다.

**팔로잉 목록에서 고르기**

`내 팔로잉 목록 불러오기` 버튼을 누른다. 로그인이 안 돼 있으면 버튼 대신 안내 문구가 뜬다.

- 불러온 목록은 **LIVE 방송이 위로** 정렬되고 LIVE/OFF 배지가 붙는다.
- 항목마다 즐겨찾기 추가·시청 목록 추가 버튼이 있다. 이미 즐겨찾기에 있으면 노란 버튼, 없으면 회색 버튼이고, 이미 시청 목록에 있으면 "추가됨"으로 눌리지 않는다.
- 목록을 못 불러오면(로그인 만료 등) 실패 안내와 함께 해당 플랫폼 홈으로 가는 링크가 나온다.

**직접 입력하기**

`채널 고유 ID`와 `스트리머 이름`을 각각 입력하고 `시청 목록에 추가`를 누른다.

- 채널 ID는 방송 주소에서 확인한다. 형식은 플랫폼마다 달라 [치지직](Chzzk.md) · [SOOP](Soop.md) 참고.
- 특수문자는 입력이 제한되고 형식이 맞는지 검사한다.
- 이미 시청 목록에 있는 채널은 추가되지 않는다.

**주의**
- ⚠️ 치지직은 **네이버 로그인 흔적이 있는지만** 확인한다. 그래서 치지직에 한 번도 들어간 적이 없어도 네이버에만 로그인돼 있으면 "로그인됨"으로 보인다. SOOP은 실제로 목록을 요청해 확인하므로 이런 오인식이 없다.

### 설정 바꾸기

`기타설정` 탭에서 한다.

| 설정 | 고를 수 있는 것 | 처음 설치했을 때 |
|---|---|---|
| 서브채널 정보 표시 | 항상 표시 / 마우스 올릴 때 **×** 프로필 사진 / 채널 이름 = 4가지 | 마우스 올릴 때 (채널 이름) |
| 대시보드 배치 | 기본형 / 반전형 / 서브하단 / 서브상단 | 기본형 |
| 자동 동기화 | 켜기 / 끄기 | 켜짐 |
| 허용 지연 시간 | 초 단위로 입력 | 10초 |

- 설정은 바꾸는 즉시 저장되고, 대시보드가 열려 있어도 **새로고침 없이** 바로 적용된다.
- 현재 버전 정보와 GitHub · X(Twitter) 링크도 이 탭에 있다.

### 공통

- 추가·삭제·저장 결과는 화면 아래쪽에 알림으로 뜬다. 약 2.5초 뒤 사라지고, 새 알림이 뜨면 이전 알림은 즉시 교체된다.
