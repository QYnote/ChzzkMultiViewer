# MultiStream — Chrome 확장 프로그램

> **다루는 내용:** 설치·사용 방법과 설계 문서 트리 진입점
> **갱신 트리거:** 설치/사용 절차가 바뀌거나 하위 설계 문서 구성이 바뀔 때

치지직(Chzzk), SOOP 등 인터넷 방송 스트리머 여러 명을 동시에 한 화면에서 시청할 수 있는 Chrome MV3 확장 프로그램입니다.

> ⚠️ 공식 개발자 API를 사용하지 않습니다. 브라우저에 저장된 로그인 세션 쿠키 방식만 사용합니다.

## 본문

### 설치 방법 (로컬 개발자 모드)

Chrome 웹스토어 출시 전 직접 설치 방법입니다.

1. 이 레포지토리를 다운로드(ZIP) 또는 클론합니다.
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 토글 활성화
4. **압축해제된 확장 프로그램 로드** 클릭 → `source/` 폴더 선택
5. 확장 아이콘이 toolbar에 나타나면 완료

> 팔로잉 목록 연동과 자동 로그인은 **해당 플랫폼에 로그인된 상태**에서만 동작합니다.

### 사용 방법

1. 확장 아이콘을 눌러 팝업을 열고, 볼 스트리머를 고릅니다 — [팝업 화면](document/PopupScreen.md)
2. `멀티뷰 대시보드 열기`로 대시보드를 엽니다
3. 칸을 나누고 크기와 자리를 조절해 시청합니다 — [대시보드 화면](document/DashboardScreen.md)

각 화면에서 할 수 있는 일 전체는 [Overview](document/Overview.md)에 정리되어 있습니다.

### 업데이트 예정 기능

- [ ] 저장한 목록을 불러와도 그대로 남는 채널은 방송이 끊기지 않게 하기
  - 지금은 담긴 채널이 하나라도 다르면 대시보드를 **통째로 다시 구성해 보던 방송이 전부 끊긴다.** 목록 대부분이 겹쳐도 마찬가지다
  - 담긴 채널이 **완전히** 같을 때만 다시 읽지 않는 동작은 이미 있다. 그 판단을 목록 전체 단위에서 **채널 하나 단위로** 좁히는 일이다
  - 남는 채널 · 빠지는 채널 · 새로 들어오는 채널을 갈라내어, 빠진 자리만 비우고 새 채널만 새로 읽어야 한다
  - 자리 배치는 채널마다 따로 기억되므로, 남는 채널은 자기 자리를 그대로 지킨다. 빠진 자리를 어떻게 메울지는 정해야 한다
  - 받은 글로 덮어쓰는 경로도 같은 길을 지나므로 함께 좋아진다
- [ ] 치지직 칸에 스크롤 막대가 새로 나타나면 `넓은 화면`을 다시 적용하기
  - 스크롤 막대가 **없다가 생기는 것**이 신호다. 넓은 화면이 풀려 방송 화면이 칸보다 커졌다는 뜻이다
  - 0.2초 간격으로 **두 번** 적용한다. 한 번만으로는 먹지 않는 경우가 있다
  - 탭으로 돌아왔을 때 넓은 화면을 다시 시도하는 장치가 이미 있다. 두 장치가 동시에 걸려 화면이 두 번 튀지 않게 해야 한다
- [ ] 트위치(Twitch) 플랫폼 채널 멀티뷰 지원 추가
- [ ] 팝업 화면을 이루는 파일들이 서로의 변수를 이름으로 직접 가져다 쓰는 구조 정리
  - 파일을 읽어 들이는 순서가 바뀌면 오류 없이 조용히 깨진다. 저장소를 읽는 쪽이 화면 요소를 직접 만지고 있어 경계도 흐리다

**개발 제외 항목**

- 통나무 파워 자동 수령 — 채팅창에 수령 버튼이 나타나면 자동으로 클릭 (네이버에서 작업장(매크로)으로 판단할 수 있는 위험이 있어 보류)
- 대시보드를 열 때 모든 방송을 소리 없이 시작 — **한 번 만들었다가 되돌렸다.** 칸마다 소리를 따로 다룰 수 없어서다. 소리는 방송 화면 안의 조절 기능에 맡기고, 원하지 않는 칸은 사용자가 직접 끈다
  - 치지직은 음량을 **채널마다 따로** 기억하지만, SOOP은 **전체를 하나로** 관리한다. 그래서 SOOP 칸 하나만 따로 끄거나 켜는 것이 성립하지 않는다
  - 음량 값을 덮어쓰는 방식은 **어느 경우에도 쓸 수 없다.** 방송 페이지가 그 값을 저장해, 다시 열 때 화면에 보이는 크기와 실제 소리가 어긋난다

### 일시적 오류 기록

재현이 되지 않아 확정 버그(업데이트 예정 기능)로 등록하지는 않았지만, 한 번 발생했던 오류를 날짜와 함께 기록합니다. 이후 새로운 버그가 발견되거나 Todo 항목을 추가할 때, 이 목록에 해당하는 내용이 있는지 먼저 확인합니다.

아직 기록된 항목이 없습니다.

### 주의 및 면책

1. 본 확장프로그램은 Naver 및 Soop의 정보수집 방해 또는 삭제 요청 시 삭제될 수 있습니다.
2. 본 프로그램 개발 목적은 단순히 '여러 동시화면 보기 위함'이며 그 외의 목적은 없습니다.
3. 본 프로그램은 웹개발을 모르는 타언어 개발자가 Claude Code를 이용하여 개발하였습니다. 처음으로 AI만을 이용하여 개발을 시도해 본 프로젝트입니다.
