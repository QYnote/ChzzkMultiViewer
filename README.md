# 치지직 멀티뷰어 Chrome 확장 프로그램

치지직(Chzzk) 스트리머 여러 명을 동시에 한 화면에서 시청할 수 있는 Chrome MV3 확장 프로그램입니다.

> ⚠️ 공식 치지직 개발자 API를 사용하지 않습니다. 브라우저에 저장된 네이버 로그인 세션 쿠키 방식만 사용합니다.

---

## 주요 기능

- **멀티뷰 대시보드** — 메인 1채널 + 서브 N채널을 3열 레이아웃으로 동시 시청
- **메인 ↔ 서브 스왑** — 서브 타일 클릭 시 영상 재로드 없이 메인과 교체
- **볼륨 독립 제어** — 서브 채널별 음소거 토글 및 볼륨 슬라이더 개별 조작
- **볼륨 복원** — 스왑 시 기존 메인 볼륨 수준을 유지하여 새 메인에 적용
- **채팅 연동** — 현재 메인 스트리머의 채팅창 자동 표시
- **팔로잉 목록 연동** — 내 팔로잉 목록을 불러와 LIVE 방송 우선 정렬 후 시청/즐겨찾기 추가
- **즐겨찾기 보관함** — 자주 보는 스트리머 영구 저장 및 시청 목록 복사
- **자동 동기화** — 설정한 주기(초)마다 메인 영상 자동 새로고침
- **와이드 모드 자동 전환** — 영상 재생 시 치지직 와이드 모드 자동 활성화
- **채팅 자동 접기** — 대시보드 내 iframe 채팅 패널 자동 숨김

## 설치 방법 (로컬 개발자 모드)

Chrome 웹스토어 출시 전 직접 설치 방법입니다.

1. 이 레포지토리를 다운로드(ZIP) 또는 클론합니다.
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 토글 활성화
4. **압축해제된 확장 프로그램 로드** 클릭 → `source/` 폴더 선택
5. 확장 아이콘이 toolbar에 나타나면 완료

> 치지직에 로그인된 상태에서 사용해야 팔로잉 목록 연동 및 자동 로그인이 정상 동작합니다.

## 사용 방법

1. **스트리머 추가**
   - 팝업 → `스트리머 추가` 탭
   - `내 팔로잉 목록 가져오기` 버튼으로 팔로잉 채널 불러오기 또는
   - 채널 고유 ID(32자리)와 표시명을 직접 입력

2. **멀티뷰 실행**
   - 팝업 → `시청 목록` 탭 → `멀티뷰 대시보드 열기`

3. **메인 화면 변경**
   - 팝업 `시청 목록`에서 `▶ 메인` 버튼으로 시작 메인 스트리머 지정
   - 대시보드에서 서브 타일 클릭으로 실시간 스왑

4. **볼륨 조절**
   - 서브 타일에 마우스를 올리면 음소거 토글 + 볼륨 슬라이더 표시

## 파일 구조

```
source/
├── manifest.json     권한 선언, content_scripts 등록
├── background.js     Service Worker — 쿠키 주입 규칙, 팔로잉 API fetch 대리
├── content.js        chzzk 스트림 페이지 주입 스크립트 (볼륨 제어, 와이드 모드)
├── popup.html        팝업 관리자 UI (4탭)
├── popup.js          팝업 로직
├── dashboard.html    멀티뷰 대시보드 UI
├── dashboard.js      대시보드 로직
├── icon16.png        툴바 아이콘
├── icon32.png        HiDPI 툴바 아이콘
├── icon48.png        확장 관리 페이지 아이콘
└── icon128.png       웹스토어 아이콘
```

## 기술 스택

- Chrome Extension Manifest V3
- Vanilla JS (프레임워크 없음)
- `declarativeNetRequest` — SameSite=Lax 쿠키 우회 및 헤더 변조
- `chrome.storage.local` — 시청 목록 / 즐겨찾기 / 설정 영구 저장
- postMessage 양방향 통신 — 대시보드 ↔ chzzk iframe 볼륨 제어
